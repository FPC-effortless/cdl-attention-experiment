# LRR-011 — matching the correct code is not sufficient for unique addressing

Woyengi Intelligence Labs — 6 November 2026.

**Decision: reject both tested auxiliary objectives as defaults.** This is an actual completed 20-pair/60-model local CPU study, not a proposed or queued experiment. Explicit read/write relation alignment worsened held-out retrieval and semantic collapse; generic self-confidence also worsened the matched control. This conclusion applies to the tested additive losses at weight0.2, not every alignment, confidence, commitment or annealing method.

Let r_q be the query relation register and r_g the pre-write register at the existing labeled correct answer-token position. The inherited base loss already includes answer-position likelihood and same-answer/different-answer query credit. It is unchanged and has no marginal entropy term.

- A control: L_base.
- B self-confidence: L_base +0.2 mean[-0.5(log max_c r_q,c + log max_c r_g,c)].
- C read/write binding (PRIMARY): L_base +0.2 mean[-log(sum_c r_q,c*r_g,c)].

The correct write state is identified by the **existing answer-index supervision**; no canonical family label, new runtime role annotation or value-only mask is introduced. All arms retain different-answer repulsion; adding a positive term nevertheless changes learning dynamics.

## Mechanistic result: correct read/write equality, incorrect retrieval

On regular H32 TEST, B and C have **100% hard query/gold relation equality**; all arms have100% hard query/gold entity equality. B/C also admit100% of gold values. Yet B answers853/1280 correctly and C758/1280. All427 B errors and all522 C errors are **last-write overwrites on an address shared with the correct record**. A has1170 correct,83 overwrites and27 empty lookups. This localizes the immediate failure to loss of distinctions between records, not failure to write the gold token.

The additional objectives did NOT simply sharpen a good representation. Final-update training query entropy increased A.1204 nats→B.3725/C.4140, while soft read/write agreement decreased .9645→.8918/.8883. This is consistent with failed acquisition trajectories, not a proof of the precise gradient-level mechanism. The poor soft-pointer results show that merely removing hard selection does not recover capability. No model that acquired>=90% regular DEV qualification dropped below it at later measured checkpoints; this statement is limited to the sampled times/cases.
