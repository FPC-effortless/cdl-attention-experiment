# LRC-TS-001: Tiny Shakespeare benchmark results

Completed 8 November 2026. This new cohort covers 14 backbone/training recipes across three paired seeds, plus three utility-head recipes per frozen V4 backbone: 42 backbone fits and nine head fits.

**Observed result:** GRU plus the lexical cache has the lowest mean held-out loss. V1 coupled and independent are effectively tied as the strongest full LRC variants. Every full learned-memory configuration scores better with learned memory disabled; explicit lexical caching helps both tested backbones.

## Protocol

- Canonical Tiny Shakespeare: 1,115,394 bytes; contiguous 90/5/5 split; 55,769 held-out next-byte targets.
- Raw byte+1 encoding, 257 output classes; approximately 43K allocated parameters. V1 width30/kernel3, V3 width26, V4-p8 width24, V4-p16 width22; two LRC/Transformer layers and one GRU recurrent layer.
- Seeds2201–2203; 2,048 AdamW updates, batch4, context128, lr0.002, 1,048,576 sampled target exposures per backbone. Final checkpoint; no test-based selection.
- Utility stage adds600 head updates and307,200 teacher target positions per seed; frozen V4 weights,50 fitted gate parameters, shared1,200 teacher forwards.
- CPU FP32, PyTorch2.5.1, Xeon Platinum8573C; one compute thread per timing process. 512-byte prefill plus128 prediction steps, five repetitions per checkpoint.
- Source/protocol frozen locally before fitting at commit f22e0d1. External GitHub publication was blocked by automatic approval review and remains pending explicit approval.

## Interpretation

- V1 independent versus coupled differs by only0.000747BPB and the paired differences change sign. The mean ordering does not establish a winner between them.
- Learned-memory disabling improves all36 applicable arm/seed observations (12 configurations including dependent gate variants). This is evidence about these trained checkpoints on this corpus and budget.
- The fixed lexical cache improves both backbones in all six paired cache-off comparisons. Causal corruption of its reads also worsens all six scores.
- True utility versus shuffled utility differs by only0.000028BPB; static final-read-off beats true utility in all three seeds. Utility-gate selection has not earned a competence claim.
- Local LRC/cache retain expensive inherited counterfactual work: only4.72%/4.70% of selected interventions have nonzero loss differences. Current implementation timing does not establish an unavoidable architectural cost.
- Secondary512-context results are in the full evidence. Transformer keeps a128-byte attention window per layer. The16-bit page capacity is not fully exercised by these short quality workloads, and its width is reduced to match allocated size.
- These size-normalized models and approximately one corpus-equivalent of sampled exposures are not convergence, GPU, semantic-reasoning, long-range retrieval, or large-model scaling evidence. Partial profiler FLOPs omit unsupported operations and cannot support total-compute rankings.

## NumPy runtime supplement

The corrected inherited cache-admission adapter uses the same trained weights. In90 retained trials, its paired median total-latency reduction was23.32% for LRC-cache (14/15 pairs faster) and11.98% for GRU-cache (11/15 pairs faster). Individual ratio ranges cross1. These separate timing trials do not replace the primary timing table.

All six cache checkpoints passed25,350 DEV output comparisons: zero argmax mismatches, maximum log-probability difference1.90735e-6, probability-sum error4.76837e-7. The superseded v1 probability-floor defect was reproduced and that runtime was not ranked. No retraining or new TEST-quality scoring occurred.

## Verification and evidence

The independent audit passed101 checks with zero failures or pending items. It verified all51 checkpoints,86,016 backbone update receipts,159 score cells,52,647 block records,255 inference trials,42 isolated training cells, and every summary/ablation conversion. It additionally replayed the first1,024 test targets on every checkpoint (52,224 predictions) with exactly zero block-NLL discrepancy and identical correct counts. This is a bounded numerical replay, not a claim of rerunning the entire test set.
