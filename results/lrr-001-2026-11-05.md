## Frozen protocol

Learned `24`-wide embedding/MLP; six concept classes, four seen aliases
per class; 120 AdamW optimizer steps using supervised canonical relation
labels. The index receives only an entity string and a learned hard relation
code at runtime. Facts and query boundaries are supplied, not learned.

Evaluation: 64 unseen documents for each H in {8,64,256,1024}, K=1,
seed 17. Each document uses novel opaque entity/value names and target
relation alias different from the query alias. Two hard-negative families
are present: same-entity/wrong-relation and same-relation/wrong-entity.
All facts are indexed before the query, and returned positions are strictly
before the query in the materialized token stream.

## Valid claims

1. A small trained *supervised lexical alias* coder maps different predicate
   words onto compatible discrete addresses within the six closed classes.
2. A hash index can retrieve the gold prior value token in this structured
   benchmark without query-to-history pair scoring.
3. Addressing entity and relation separately is causally relevant: the
   relation-only ablation fails as irrelevant facts increase.
4. Runtime index probes are bounded in the observed protocol, while writing
   H facts costs O(H); the query result is a list of token indices, not an
   attention-weighted hidden-state combination.

## Exclusions and next falsifiers

- Not a proof of generalized semantic relation discovery: training provides
  the true relation classes; all predicate lexemes are seen at training time.
- Not a language-model attention replacement: entity extraction, span
  segmentation and query structure are supplied; no perplexity or generation.
- Not a proof of O(1) full pipeline, GPU performance or constant end-to-end
  latency: writing H records is linear, memory is O(H), and CPU medians are
  descriptive. P95 timing variation at H=256 is visible.
- No CASM-X19D role-constructor code or CASM-X20U counterfactual estimator is
  imported. They motivate the next causal experiment only.
- LRR-002 should remove **explicit relation class labels** and learn
  relational addresses from retrieval-success / local credit; LRR-003
  should remove provided fact/entity boundaries and compare against a
  parameter-matched Transformer on meaningful language benchmarks.

**Gate:** accept the narrow structured-index pilot only; hold architecture
integration and any model-level efficiency claim.
