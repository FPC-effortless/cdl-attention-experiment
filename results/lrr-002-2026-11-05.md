## What this establishes

1. End-task *pairwise answerability supervision* is sufficient to recover
   six discrete address clusters on this closed synthetic lexicon when a
   balanced code-use objective is used.
2. The resulting codes can drive causal dictionary/posting-list retrieval
   with no Transformer attention, no per-query full-history candidate scoring,
   and no weighted aggregation of prior token vectors.
3. The balance regularizer materially changes both the trained hard
   addressing geometry and downstream token-position retrieval.
4. The result improves on LRR-001's **explicit class-supervised** pilot along
   a specific axis: the encoder now sees only pair labels. LRR-001 remains
   the fixed indexed-runtime and supervised-ceiling control.

## Limits and honest exclusions

- Pairwise labels cover **all 276 lexeme pairs** in the 24-word controlled
  vocabulary. This is not unseen-lexeme or unseen-pair generalization.
- The number of relation codes (**six**) is supplied, not inferred. Balanced
  code-use loss depends on that assumption; unknown cardinality remains a
  substantial unsolved problem.
- Fact/query segmentation and entity surface identity remain scaffolded.
  The test does not learn parsing, entity resolution, pronouns, coreference,
  nested structure, or compositional multi-hop relations.
- Training uses a product of two independent categorical code
  distributions **only to learn addresses**. Inference is hard indexed
  retrieval, not query-key self-attention or a weighted value mixture.
- Query-time single-probe work does not imply end-to-end O(1) context
  handling: ingest and memory grow with history, and no matched GPU or
  language-model latency test was performed.
- No CASM-X19D / CASM-X20U code was directly reused. Their address and
  local credit insights motivate, but are not validated by, this separate
  lexical pair-credit experiment.
