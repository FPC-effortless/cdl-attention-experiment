# LRR-012 — direct record separation did not improve the matched control

Woyengi Intelligence Labs — 2026-11-06.

**Decision: do not adopt either tested additional negative-separation term.** This is a completed prospective local CPU study:20 paired model/data tuples,60 trained models. The unchanged control scored98.125%, stronger query separation97.890625%, and direct record separation97.578125%. Each arm had exactly1/20 semantically collapsed runs and19/20 DEV-qualified runs. No incremental or location-specific advantage is established. This does not refute negative-separation learning generally.

Let D(p,r)=-log(1-min(dot(p,r),1−1e−6)). For two different-answer questions about the SAME literal entity/history, q_a/q_n are pre-query relation states and w_a/w_n are pre-write states at their existing gold answer-token positions.

- A control: inherited two-sided L_base unchanged.
- B query strength control: L_base +0.2 D(q_a,q_n), increasing total query-negative weight0.2→0.4.
- C record separation, PRIMARY: L_base +0.2 D(w_a,w_n); original query-negative weight remains0.2.

Only existing answer indices locate the write records; no family IDs, new role tags, oracle writer mask or new runtime annotation enters the model. Generator-defined same-entity/different-relation supervision remains a privilege. Latest-value consistency prevents false negative labeling of obsolete duplicate records. Same coefficient/pair counts do not mean equal gradient magnitudes. No extra positive alignment/confidence/entropy terms.

Related primary background: Khosla et al., Supervised Contrastive Learning, NeurIPS2020/arXiv:2004.11362. This applies a known contrastive principle to the LRR register; it is not invention of contrastive learning or code from that work.
