## Abstention and false-answer behavior, H=32 (five seeds ×64 cases)

- **Known predicate but no matching fact for the queried existing entity:** credit arm **41/320 = 12.8125% false answers**, above registered ≤10% (FAIL). Per seed 0,0,22/64,0,19/64; the failures are concentrated in seeds 43 and 45.
- **Unknown predicate surface `unseenverb`:** credit arm **0/320 false answers**, ≤10% gate PASS on this single synthetic token. The unknown word maps to a shared `<unk>` embedding; rejecting it is *not* evidence of general semantic novelty handling or learned synonym induction.
- **Strong grammar-aware symbolic parser plus outcome-trained union-find:** 100% correctness across all positive conditions and zero false answers on the negative controls. It has the benefit of a supplied predicate-word grammar, but it still defeats both learned arms on this limited task.

## Post-hoc mechanism attribution (not preregistered gates)

The independent local analysis tool reloaded each frozen checkpoint and reconstructed the same 64 H=32 test examples. It reproduced exactly the reported recall counts. At the **failed** seed 43: only 5 correct, **42 abstentions and 17 wrong overwritten retrievals**; 22 queries matched the correct gold-record address and the gold value's write gate was ON in all 64 cases. Hence seed 43 is principally an **entity/relation address consistency and collision** failure, not simply absent value writes.

Seed 45: 46 correct, 6 abstentions and 12 overwrite/collision errors. At seed 42, all 64 queries were correct but there were **2,112 non-value writes** across the 64 contexts, about 33 unnecessary writes per document: successful retrieval can coexist with poor write precision and memory overhead.

The diagnostic is a post-hoc checkpoint audit, not an independent optimizer run. It cannot be used to change the frozen pass/fail criteria or select a preferred seed.

## Mechanism versus attention and scientific boundary

- The runtime **hard** direct-address retrieval does not form an attention matrix or score a query against every previous token. The encoder/update procedure still processes the input history, and memory/storage grow with the number of indexed positions.
- Training **does** compute dense position-wise soft agreement to backpropagate from known answer-token positions. It is **not** a wholly non-attention-like learning mechanism; only the inference index avoids token-pair attention.
- Entity keys are copied literal surface strings (no pronoun resolution or identity coreference), four hidden relation families and eight preconfigured code slots remain supplied, sentences use a restricted question/period grammar, and there is no trained language-model loss.
- The symbolic ceiling is 100%, and no strong Transformer/SSM retrieval baseline or matched GPU training/decoding throughput was qualified. Therefore no claim of architecture-level superiority is authorized.

## Decision / successor

Preserve ALL ten checkpoints and negative outcomes. PR #41 remains draft and unmerged. The next discriminating objective is **to eliminate the hard-seed address collision and extra non-value writes under counterfactual state credit**, while preventing known-but-absent false answers and testing unseen lexical/syntactic phenomena independently. An address-correctness advantage must survive matched symbolic, trained attention and current recurrent references before becoming part of a language-model layer.
