# LRR-010 — 20 paired tuples: schedules and direct code-use entropy

Woyengi Intelligence Labs · 6 November 2026

**Decision: do not adopt the tested entropy term.** It did not demonstrate increased expected retrieval or reduced semantic collapse. This is a negative result for one prospectively selected coefficient in the current architecture, not a theorem against entropy regularization. Interleaving remains the existing control; a general schedule ranking is not statistically established.

## Definitions fixed before fitting

Qualification is >=90% regular DEV exact retrieval. Semantic merged-code collapse is >=10% of different-true-family query pairs sharing a valid hard query code in a128-history balanced DEV diagnostic (4 families ×4 aliases ×8 cases). It is a task-specific semantic collision definition, not merely low accuracy or low code count. Family labels are evaluator-only. Severe starvation is effective hard-code count<2 or largest valid-code share>=90%, separately reported.

Non-collapsed conditional accuracy is descriptive: no semantic collapse and <=10% missing query codes. It is never substituted for the all-seed paired outcome because treatment changes survivor membership. Time to qualification is observed only at0/100/250/500/750/1000 checkpoints.
