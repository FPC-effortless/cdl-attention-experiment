# LRR-010 — twenty paired tuples: schedules and categorical usage entropy

Date: 2026-11-06. Status: prospective protocol, committed before pilot or confirmatory fits. Parent source LRR-009 at 1c04002238605da1e83617807ddf55012cba3a03; original runtime remains unchanged. ## Questions and matched design
Primary D-A: does marginal query relation-code usage entropy improve expected hard retrieval and reduce semantically collapsed addressing? Secondary B-A and C-A: how reproducible are schedule effects? This is not a full schedule-by-entropy factorial.

80 confirmation fits: 20 distinct tuples (model seed 11001..11020, bank seed 21001..21020), four arms each. A interleaved, B clean-first, C augmentation-first inherit exactly LRR-009's objective and schedules. D uses A's schedule and adds ONE term -lambda*H(mean_batch r(query)). No EMA, resets, annealing, commitment or per-example entropy term; no architecture changes. The existing same-answer/different-answer objectives stay unchanged.

Every fit: 4,748 parameters, 1,000 AdamW updates, lr .004, grad clip 2, 500 clean and 500 augmented events, 48,000 labeled question-view exposures, 4,000 unique source histories. The bank and fixed perturbations are reused once clean and once augmented as in LRR-009. Within a tuple, initial model weights, complete event multiset, labels, masks and Gaussian perturbations are identical. A and D have identical order. Continuous optimizer state; no early stopping, extension, seed replacement or failed-run exclusion. Additional entropy computation is logged, not claimed free. Up to 3 separate CPU worker processes, one PyTorch thread each; no new GPU jobs.

## Pilot selection, fixed before pilot data are fitted
12 limited pilot fits: model seeds 10901,10902,10903 paired with bank seeds 20901,20902,20903; interleaving and lambda in {0,.02,.10,.30}, all at the same 1,000-update recipe. Only held-out DEV histories are evaluated. No confirmatory model seed, bank or TEST performance is inspected during selection. Choose a NONZERO lambda by lexicographically (1) maximizing number of final regular DEV-qualified seeds (>=90%), (2) minimizing number of semantic-collapse diagnostic seeds, (3) maximizing mean unfamiliar-filler DEV recall, (4) maximizing mean regular DEV recall, (5) minimizing lambda. Zero is a pilot reference, not an eligible D choice. Record all 12 pilot outputs. Commit the chosen coefficient before any confirmation fit. This pilot budget and selection rule cannot change based on results.

## Definition of collapse, qualification and meaningful distinctions
These are separate quantities, not interchangeable labels:
- Qualification: >=90% exact recall on 128 independent regular DEV histories. Also evaluate their position-preserving unfamiliar-filler transforms. First observed qualification at fixed steps 0,100,250,500,750,1000; this is checkpoint-censored time, not exact convergence time. No selection of training continuation.
- Semantic diagnostic DEV: 128 histories balanced by true relation family (4), query alias (4 per family), 8 examples per cell. Uses only legal TRAIN-domain ordered alias pairs but distinct diagnostic histories. Relation labels are EVALUATOR-ONLY. Never enter the optimizer, entropy term or inference. Save individual relation codes, query/gold address agreement, writer/overwrite/collision outcomes.
- Hard occupancy, largest-code share and effective count exp(H(p_hard)); missing register is separate from valid code occupancy. Severe code starvation: effective count <2 or largest valid-code share >=.90 (empty-code population is starved). This does not itself diagnose semantic correctness.
- Semantic merged-code collapse: fraction of pairs with different true relation families but the SAME valid hard query code >=.10 in the balanced semantic diagnostic. The denominator is all different-family pairs; missing codes never count as equal. This task-specific definition is independent of accuracy and frozen prospectively. Also report H(hard_code | true_family), per-family code counts, missing-code fraction, query/gold-address match and within-history cross-relation record collisions.
- Non-collapsed descriptive stratum: no semantic merged-code collapse and <=10% missing query codes on final semantic DEV panel. Conditional TEST accuracy in this stratum is descriptive only, not a causal comparison across unequal survivors. Retain unconditional all-seed paired means and a both-qualified pair subset with selection caveats.

## Data and outcomes
Use unchanged LRR-008/009 generator, tokenizer, augmentation, answer policy (latest record), restricted aliases and code capacity. New model/data tuples, DEV and TEST history banks. Primary endpoint H=32 same-position unfamiliar-in-vocabulary filler substitution exact gold token recall, 64 independent histories per seed, same histories across arms. Secondary H=7/128 and regular, familiar-filler permutation, unknown-token filler, extra familiar positions. All source fits finish before first trained-model TEST evaluation. Keep original alias exclusions and no TEST (1,3) or DEV (2,1) ordered pair in training; the semantic diagnostic uses legal TRAIN pairs only.

Persist raw false reads at H=32 for (a) known entity/predicate without any supporting relation and (b) unknown query predicate, 64 each per seed/arm. Validate negative facts and record every decision; no untrained abstention capability gate. These rows are NOT an every-position language-model false-read estimate. A separate trained gate is not included in the 80-fit intervention because it would confound the intended comparison; LRR-006 remains the independently trained selective-answer lane. Report raw behavior prominently rather than suppressing it.

Symbolic reference: grammar-aware parser plus union-find trained on exactly the same answer-labeled source histories per tuple; retain its privileges. No newly qualified attention/SSM model, real-language addressing or full-LM claim follows from this study.

## Statistical plan and decisions
Unit of replication is the independent model-seed/data-bank tuple (n=20), not question count. Primary estimand mean paired TEST D-A difference. Save all per-seed rows, distributions, win/tie/loss, median and between-seed SD; 50,000 paired seed bootstrap resamples (fixed RNG 2026110610), two-sided 95% percentile interval; exact paired sign-flip randomization over 2^20 assignments. Report conditional results and code-collapse frequency separately. Wilson 95% intervals for rates, exact McNemar on discordant pairs for semantic-collapse contrast. Secondary schedule tests Holm-adjusted across B-A and C-A, kept separate from the primary entropy hypothesis. No optional stopping.

A useful entropy result requires mean primary D-A >=.05 and 95% paired interval lower bound >0, at least 3/20 fewer semantic-collapse runs than A, and no >.05 absolute aggregate deterioration in either raw false-read panel or OOV filler recall. All conditions are disclosed jointly; lack of significance is inconclusive, not proof of equivalence. No claim collapse is eliminated, even if 0/20. Provide robust default decision only within this symbolic-language scaffold.
