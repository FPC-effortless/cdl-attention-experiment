# COG-ATTN-071–080 · Adaptive commitment and verified skill acquisition

The local tracker maintained its transaction boundary through every tested workflow, but it still committed semantically wrong actions for which it had permission. On reserved wording, 68 of 188 authorized commits selected the wrong operation or ticket. Acquiring language from witnessed changes helped more than increasing model confidence. Active probes earned their cost when a decision required information that ordinary observations could never supply.

This cycle has its own branch and protocols. It starts at the PR #72 merge, uses pinned code from PR #73 and the relevant predecessor branches, and preserves their separate qualification decisions. The supplied cycle description was the basis for the new protocol. The linked downloadable specification was not present as an attachment in this workspace. ## What reached the ledger

Each request has one of eight operations and four possible ticket targets. User statements, repeated paraphrases, mirrors, revisions and silence enter a provisional workspace. The candidate generator ranks all 32 pairs. The controller can ask about one slot. The simulated reply can be unavailable. A shadow proposal holds versions for both the ticket and its dependent activity record. The external-approval analogue signs the exact proposal when the current workflow permits it. High-impact operations also require an explicit positive approval bit. Each admitted transaction updates the ticket, activity record and journal atomically. A signed permission can cover an action that the user did not mean.

## Which interventions earned their costs

**Causal evidence.** Passive telemetry only exposes co-varying flags in the silent condition. Four different rules produce identical ordinary observations there. An intervention can safely separate the flags. Regular audits identified silent shifts after an average of 4.49 operations. On informative streams, active recovery took 3.32 operations on average versus 6.92 for passive recovery, but cost 3,696 units against 1,512 across 72 episodes. In the demand-triggered follow-up, the hidden rule mattered for an explicit counterfactual diagnosis. With probes unavailable and co-varying observations, the repaired policy returned unknown on all 72 diagnoses. With probes available it made all 72 correctly. On informative streams passive recovery also got all 72 right, at 1,512 units versus 4,470 for demand-triggered probes. The original 067 empirical sensor policy requested zero redundant observations on the separate channel-transfer test. The diagnostic arm identified the off-diagonal consequence in 96/96 available cases and deferred in 96/96 unavailable cases. [Original panels](results/rep/subsystems.json) · [Acquisition-policy transfer](results/diagnostics.json) · [Demand-triggered probe traces](results/admission.json)

**Experience and authority.** In the teacher-assisted transfer, a frozen entailment model scored 1,115 distinct utterances against eight hypotheses, taking 76.70 seconds on CPU for the batch. Every session using that table records the full batch time as a separate conservative charge. The reported tracker wall time measures lookup and all other live computation. No teacher-assisted speedup is claimed. In the attention-free follow-up, 48 raw support utterances and before/after state pairs yielded 141 text fragments that agreed across training roots and a validation root. Fresh stream seeds on those exposed phrase families improved provisional interpretations from 157/576 to 513/576. The exact planner and cached planner produced the same 224 commits and 29 semantic errors. The root labels represent simulated witnesses with programmed semantics. Neither human independence nor autonomous discovery of the underlying operations has been established. [Teacher scores and input hashes](results/teacher.json) · [Attention-free acquisition](results/admission.json)

**Execution economics.** Across the six primary and reserved sessions, full and primitive controllers produced identical actions. Reuse reduced charged work from 120,275 to 94,971 units, but aggregate measured wall time was approximately 3.36 seconds with reuse versus 3.32 seconds for exact primitives. The prefix-based cost gate selected caching on the novel topology, yet its own measurement and verification costs remained on the bill. Against the stronger semantic-memoization control in the final follow-up, adding plan caching reduced work from 73,836 to 56,711 units. The three end-to-end speed ratios were 0.978×, 0.992× and 1.024×. A separate scoped 068/069-style packed-vs-folded readout using the actual 068 authority gateway reproduced the same decisions but gave inconsistent speed ratios across seeds. [Timers and effective work by stage](results/primary/sessions.json) · [Full-cost repair measurements](results/admission.json)

The simulator charges 20 units per clarification, 5 per diagnostic probe and 10 per approval request, in addition to local stage operations and primitive attempts. These prices are assumptions. Wall time includes local model fitting and calibration, candidate generation, reading evidence, authorization, SQLite, revalidation, rollback and planning. It excludes human wait time, production networking and model development. The planner uses supplied checklist worlds. All timers are single-host CPU observations; setup repeats per independently timed session. Only three sessions contribute to each panel's paired intervals. This cycle does not qualify GPU scaling, production distributed authority, or new operation discovery.

The extended GitHub-hosted replay also matched the third-cohort decisions, the attention-free dictionary and demand-probe outcomes, and all adversarial correction records. It used the published teacher logits for the transfer comparison. The restricted GitHub comment classifier was re-fitted locally and reproduced its per-comment predictions. None of these checks substitutes for replication by a separate investigator. The 070 USGS observational branch remains on its own source-ingress hold; this cycle did not evaluate or promote it. ## Authentic tracker replay and admission decision

The final transfer fed 2,200 actual GitHub comments through the fitted text model and transaction workspace in chronological order. A validation-selected staging threshold flagged 765 proposals. Earlier timed verification requests supplied 446 responses for those candidates; 319 lacked a recorded response. The separate observation ledger mirrored 53 behaviorally correct changes. An observation credential was refused by the execution ledger. No comment supplied an execution credential, so the prospective ledger recorded zero transactions. Elapsed local time including model loading, inference, durable local stores and verification was 9.49 seconds. Recorded observation delays summed to 331,964 seconds across requests that could overlap. This is a two-domain retrospective replay, not autonomous permission on GitHub. [Frozen transfer design](AUTHENTIC_WORKFLOW.md) · [Outcomes and arrival timestamps](results/issue-workflow.json)

Keep the transaction boundary, signed revision chronology and explicit unknown response when diagnostic evidence is inaccessible. Use verified phrase induction as a bounded semantic aid. Defer speculative construction until disambiguation on this workload. Retain exact primitives as the cost reference. Additional phrase support improves correct commits but the strongest matched complete-task comparison did not justify an automatic planning-speed promotion. The central 95% first-pass issue-workflow gate remains open.
