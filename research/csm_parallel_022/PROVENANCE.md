# Provenance and scope

The owner supplied a prose summary of CSM-PARALLEL-001, describing nine executor configurations, 2,709 correctness comparisons, and CPU timing improvements. No actual package link or Library attachment accompanied that summary. Searches of accessible Library title/content, the research Space index, saved conversation history and the available workspace did not locate that archive. This does not prove it never existed. Its source, raw measurements and experiment environment are currently unavailable for independent verification; this study does not adopt its numerical claims as verified evidence.

CSM-PARALLEL-022 is a separately authored implementation and prospective comparison, not a recreation of an unseen package. The reused reference semantics are pinned to public repository FPC-effortless/cdl-attention-experiment, commit c5b53d973192d3f1842185a4ec51d55c7e958b38, research/csm_conditional_019/reference_executor.py, SHA256 bec9d5c1a05f6c50b43ed68fc3e6040064f76036d9d2fbecb024eb2dd81a7059. That file was independently recovered from the correct checkout; an initial lookup in an older checkout failed and was not treated as proof of missing public source.

Snapshot COPY, live identity LINK, deletion/recreation, absent reads and bounded cyclic reads retain that reference contract. IFSET is an explicitly defined extension: resolve the supplied source from current state, compare with the supplied expected natural number, and SET the destination iff equal. Learned controllers must infer these fields from text; the conditional comparison and payload transport are engineered.

Native graph recurrence has not been made arbitrarily token-parallel. Each instruction parser is context-independent, and the executor preserves serial order inside each bank. Cross-bank dependencies cause conservative whole-program serial fallback. Real OpenMP concurrency therefore applies only to independent regions; parser batching and caching are separately described.
