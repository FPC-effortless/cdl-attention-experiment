# REPAIR-009-DOWNSTREAM-001 — locked before dispatch

Goal: teach native pretrained memory access and compare competent complete same-interface models, not substitute a typed interpreter, oracle read/write or separate classifier for native generation. All CPU, standard GitHub runners, no paid runners, no merge or deployment. Preserve exact REPAIR-009 terminal parents.

Eight arms × three seeds (9001,9011,9029): HH, U, A0 continued from exact 8192-update REPAIR-009 parents; corresponding HH_random, U_random, A0_random initialized using the original architecture and paired seed; HH_ctx and U_ctx continued from exact parents with a zero-initialized residual contextual role/address/payload router over a 64-dimensional causal affine state. Native architecture, protected/background matrix, temporal sides, and original tied vocabulary are retained. Extra router has measurable extra parameters; compare it with its own parent, not claim exact parameter equivalence. All arms receive the same raw text, endpoint CE, sparse supervised role/address/value labels during training and the same real-prose rehearsal. No label injection at inference; auxiliary supervision is a developmental intervention. A0 uses the same Local supervision but its attention blocks do not consume protected slots. GPT is not included in long-history downstream training because its fixed 768-byte absolute-position implementation cannot carry 8192 without redesign; A0 is the long-context attention control.

Training: fixed 1024 AdamW updates per fit in three stages: 256 at 768 bytes, 384 at 2048, 384 at 8192; four independent raw examples per step (one each recall, revision, ordered relationship, permission), microbatch 1; actual carried state through every 128-byte chunk, non-reentrant activation checkpoint, no detach. One real 768-byte next-byte rehearsal window per step from the pinned original TRAIN article inventory. 4096 semantic training examples per fit; identical data order per paired seed; no official validation or TEST used for training. All parameters trainable, AdamW 2e-4, beta(.9,.95), matrix weight decay .01, clip 1; fixed schedule, no outcome-driven tuning. Native endpoint full-vocabulary CE plus 0.5 role, 0.5 address, 0.5 payload sparse CE and 1.0 prose CE. Labels occur at record completion and question endpoints; they are not supplied at inference. Role/controller design and fixed eight known names constitute a finite developmental domain; held paraphrase templates never appear in training. This is not open-world semantics, explicit computational graph construction, independent evidence truth, or broad instruction tuning.

Each stage checkpoints optimizer, RNG, model, source/data/parent hashes and step; fixed stage budgets are mandatory. Partial checkpoints preserved on timeout/failure; no reduction or credit for incomplete fits. Engineering preflight runs actual 8192-position trajectory and finite backward, native chunk/causality parity, zero-residual parent parity, paired data checks and safe restoration. Stage matrix max-parallel 6. Final held evaluation uses separate original TRAIN-development articles for filler and prose (never training); 32 counterfactual pairs per task, length and seen/held template family (1536 questions per model). Identical questions with altered factual or relational history, unrestricted native byte exactness and both-correct pairs. Query-only, state swap and protected-row removal diagnostics. Track actual read role/key selection; swap is causal intervention, not qualification. Per seed require >=95% seen and >=90% held both-correct at every length/task, zero false positive permissions on prohibited cases, <=.05 BPB regression versus exact pretrained parent on entire original development corpus. Random arms compare learning transfer; no parent prose-regression requirement on random initialization. Equal examples/updates and near-parameter native controls, record CPU timing; not measured FLOP matching. Do not treat even passing finite tests as autonomous authorization or graph competence.
