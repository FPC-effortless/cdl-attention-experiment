# CSM-LIFECYCLE-012: learned selection over a common exact typed store
Prospective bounded experiment. No outcomes inspected before freeze. Nine fits: state-conditioned 48-byte parser (60,434 parameters), stateless 48-byte MLP (60,658), GRU (28,178), seeds 101/202/303. All share the same exact four-record executor, opcode/destination/source/value labels, training schedules and fixed endpoint. The primary near-parameter-matched comparison is state versus MLP. This is a new structured hybrid, not a repair of native CSM checkpoints, discovery of memory semantics, or general language qualification.

## Data and operation contract
Frozen explicit operation programs are rendered into two familiar text forms; supplied operation records generate training labels and evaluation targets, never inference inputs. TRAIN has 1,024 histories; DEV 2,048, with held-out COPY/LINK bindings and composition families listed in DATA_DESIGN.md and DATA_COVERAGE.md. Complete histories/nonces are disjoint. Identities A-D and payloads a-d remain familiar. A declared finite grammar and provided executor make this easier than general prose. Ignore-prefixed commands are no-ops. DELETE leaves incoming live identity references intact; recreation revives them. COPY reads pre-operation effective payload; copying absence yields absence. Cycles resolve unknown. QUERY leaves records unchanged only when the learned operation actually selects QUERY. All four final query actions and identities must be learned; score positions are external, not fed into inference. Intermediate queries, absent records, cycles, aliases and snapshots are retained.

## Execution and learning
Embedding32; 48-byte causal frontend32; state controller sees only its own predicted memory's 44-dimensional one-hot features. No gold/teacher state. Stateless MLP width64; GRU hidden64. One packed 18-logit head splits 6/4/4/4. Greedy decisions drive the exact executor. Hard state has no gradient through operation choice. Opcode cross-entropy covers every byte, with TRAIN-only no-op weight1 and positive-class weights n_noop/(5*n_class). Destination loss applies to all true actions, source only COPY/LINK, payload only SET. Sum four losses; unused fields masked. No auxiliary answer loss. Every arm gets identical supervision; exact executor supplies semantics/readout. Models accept only tokens and owned state.

1,024 updates per fit, 16 histories sampled with replacement from a uniformly sampled TRAIN condition, AdamW lr .003, default weight decay .01, clip norm1. Same Random(seed) schedule across arms; fixed endpoint, no outcome-based selection. 9,216 total updates and147,456 history exposures. Single 1,800-second native attempt; no paid compute or protected TEST. Training curves are diagnostics, not convergence proof. Non-state parsers omit execution during training because predicted memory cannot affect their parser outputs; inference always includes execution. State parser executes own actions throughout training. This is matched exposure/supervision, not matched FLOPs.

## Implementation safeguards and cost
Causal frontend may precompute windows; state-dependent controller stays sequential. Integer executor computes reads/clones on any batch column with at least one predicted action. Entire all-noop columns are skipped; mixed columns still perform no-op rows' work. Features are cached until predicted writes; parity against always-recomputed features required. No claim of globally sparse kernels. Independent preflight must exercise actual finite loss/backward without optimizer updates, label/semantic integrity, full/segmented execution, query-state preservation under correct action, future-token perturbations, and tracing parity. Trace collection is disabled for timings only after parity validation.

Full inference timings include text encoding, initialization, parsing, memory maintenance, source resolution and all uninterrupted queries for a common eight-session workload; warmup then three repetitions. Split ingestion and query costs are additional measurements, not forced replay baselines. Persistent tensor state and maximum sequence lengths are separate from peak temporary memory. Training wall time reported separately. No 12:1 composite unless comparable quality gates pass; maintain quality/cost frontier.

## Gates and evidence
Fixed TRAIN calibration uses all 64 histories per condition, not a cherry-picked subset. Every seed and every DEV condition must achieve at least95% query accuracy, complete-final-map accuracy, exact-final-record-state accuracy, complete-session accuracy, and canonical exact-event precision and recall. Complete-session requires every emitted non-noop operation and relevant field exactly match gold (no false/missed operation), all query answers match, and final state match. Report extra queries, query-time wrong writes, missing queries, wrong fields, and terminal state discrepancies. Absent-answer and present-answer strata remain separate. The historical95% gates remain failed; success here is only this new declared task. Report each seed/condition even on failure. No reinterpretation of averaged rescues as a pass.
