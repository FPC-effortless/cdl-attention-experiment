## Supplied structure versus learned behavior
All arms receive the same causal recognizer for single ASCII uppercase identity tokens, first-occurrence interning into four records, candidate masks and exact typed executor. This provided lexical/entity boundary mechanism is not learned entity recognition. No operation/role parser or regex source/destination resolution is used by inference. The network learns opcode, role mention selection and SET payload; exact COPY/LINK/DELETE semantics are supplied.

A one-byte buffer resolves pending previous byte with observed neighbors. It is appended once to48previous-byte history; current-byte lookahead is a separate embedding with all uppercase bytes masked identically. No past embedding/state/output is backpatched. A candidate is recognized only with both nonletter boundaries observed, never via segment-end flush. Both cases count as ASCIIletters. Digits are nonletters under this declared grammar. Tied models map recognized identity bytes to one token; untied retain their raw identity byte. Other literal text is preserved. All recognized identities, including ignored commands/queries, are interned. A fifth distinct identity rejects the segment before memory execution because lexical prefill is performed first; caller state remains unchanged (segment-atomic admission, not rollback of earlier calls). Explicit no-candidate admission masks all non-NOOP operations, shared by controls. No gold fallback.

Two learned role heads score48candidate positions, so an address must appear in this recent buffer; no claim of selecting an unmentioned distant identity. Per-slot logits are the maximum score among positions assigned that slot. Identity cross-entropy therefore agrees with hard mention/slot argmax, without gold mention-position supervision or summing duplicate probability masses. Relevant destination/source fields are learned even for queries. No-candidate role logits are unused zeros; valid target-bearing actions have a candidate. All models use owned predicted state, never teacher memory. The state controller sees only canonical slot features, not raw symbol tables.
