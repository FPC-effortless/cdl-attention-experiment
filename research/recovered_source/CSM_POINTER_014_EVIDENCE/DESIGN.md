# Prospective014 design: reusable identity roles, not another memory payload repair

Motivation is audited013: wrong destination/source identities dominate selected withheld COPY/LINK errors, with no SET payload/opcode failures in that subset. The next candidate keeps the exact executor but changes how identities are represented and selected. It does not fix native CSM weights.

## Shared engineered interface
Raw text contains single-uppercase identity tokens. A causal scanner recognizes only a single ASCII uppercase letter bounded by non-ASCII-letter bytes. Recognition waits for the following byte; no future lookahead. Distinct symbols are interned into four canonical slots by first mention. Fifth identity rejects explicitly. This is provided identity tokenization/metadata, not discovered entity recognition. It does not identify semantic source/destination roles. Every control receives the same candidate positions and canonical-slot mapping.

A learned parser chooses opcode, destination mention, source mention and SET payload. Neither gold roles, action positions, regular-expression role rules nor fixed source/destination offsets enter inference. Two learned role heads score all48 recent positions; ineligible positions are masked using the shared lexical recognizer. Per-slot logits are the maximum score among candidate positions bearing that slot. Argmax therefore chooses a learned mention position/identity consistently with supervised canonical-identity loss. Multiple mentions of one identity are not separately labeled. Op/value heads remain learned. QUERY identity is selected by the same destination mechanism.

The tied candidate replaces recognized identity bytes with one common learned identity token. The non-equivariant pointer control retains raw identity bytes, with identical metadata, role-head architecture and supervision. One-byte buffering resolves the previous byte only when its following byte arrives; it is appended once to a48-previous-byte history. A separate current-byte lookahead embedding masks every uppercase byte identically in both arms. No earlier embedding/output/state is backpatched. At clause punctuation the immediately preceding identity becomes available to the pointer. The buffer carries across segments and its cost is counted. Literal command text is not globally rewritten.

Canonical slot order depends on first occurrence, not letter value. Thus a consistent bijective renaming of identity tokens preserves candidate slot sequences and tied neural inputs. The exact executor operates canonical slots; logical records decode through the intern table. This is a limited symmetry guarantee, not a theorem of parsing accuracy or language competence. Mathematical proof and actual raw-scanner causality/parity/rename tests must state their distinct scopes.

## Planned comparisons
Primary tied versus untied mention-pointer parsers, with the same48-byte context and executor. Include state-conditioned and stateless variants if budget permits to separate interning/role selection from state access. Retain audited012MLP/GRU results as historical references, not fresh matched-control superiority evidence. A freshly trained GRU mention-pointer is a possible strong comparator, subject to prospectively fixed budget and runtime preflight. Registered parameters and effective unused/tied parameters must both be reported; equal parameter totals alone are insufficient.

Fresh generated histories use the same explicit grammar but new nonces/permutations. TRAIN still excludes declared COPY/LINK bindings. DEV contains fresh A-D cases and paired E-H relabelings. E-H identities are never training identity tokens. They remain engineered single-character symbols recognized by the shared scanner; this is not unrestricted unseen-name/entity recognition. Renamed histories reuse underlying programs and must not be counted as independent structural examples. No protected TEST is used.

Training remains free-running owned predicted state. Gold operation/identity/payload targets are training supervision, converted externally to canonical slots; no gold memory state. 95%every-seed/every-stratum query/map/record/session/event gate remains unchanged. Earlier failures remain failures. Full timings include lexical scanning/interning, neural parsing, memory maintenance and uninterrupted queries. Preprocessing cannot be omitted from cost because it is now part of the design.

Exact model dimensions, fitted arms, budget and loss must be independently prereviewed and frozen before any fit. No experimental outcome has been inspected for014.
