# CSM-ROUTING-008: free-running soft-routing repair diagnostic
## Hypothesis and scope
The unchanged native CSM in language007 was trained with free-running recurrent state, NOT teacher states. Its chance calibration cannot by itself establish architectural inability. We test whether replacing hard-forward categorical decisions by soft probability mixtures improves end-to-end credit assignment at a fixed budget. Softening changes forward computation as well as surrogate gradients; any difference cannot isolate gradient bias alone. No original CSM repair or old lifecycle gate clearance is claimed.

Three arms: native hard CSM, same-parameter fully soft CSM, and matched-size GRU. All from scratch, seeds101/202/303, identical512updates×16examples schedules, AdamW.003,clip1. Same native source except routing switch, all seven categorical choices softened together. Soft inference remains dense (no attention-free sparse-efficiency claim); posthoc hardening of soft checkpoints is a frozen diagnostic, not a fourth fit or deployment endorsement. All native CSM state still free-running during training/eval. No teacher forcing of states, addresses, operations or values; final byte answer only. This experiment does NOT test teacher-state mismatch from typed006, which is a separate issue.

TRAIN data is exactly previous007 generated TRAIN; fresh DEV nuisance seeds19000+ use four same task panels: familiar facts, correction, longer delay, unseen phrasing. Exposed hypotheses but fresh prospective histories; no protected TEST. Four familiar codes and one entity, controlled English-like templates, not general language or broad generalization. Paired histories differ in answer but suffix identical. Independent nuisance group is pair, not tokens. Full/reset/swap interventions as007, state reset preserves position and resets links to identity. Soft mixtures include links,cursor,edit decisions and operators; they need not obey typed record invariants.

Qualification retained: every seed requires95%train-probe accuracy, each DEV panel95%full-vocab accuracy and90%both-pair-correct, positive correct-state-vs-reset on correction+long. Every failure remains recorded. No convergence guarantee from512updates; calibration failures are not incapacity. No efficiency promotion without quality. Timing complete inference8histories,3repeats, tensorization+init+ingest+readout, 1CPUthread; model load excluded. Training cost separate; parameter count not compute matching. Raw curves,checkpoint hashes,9producer checkpoint replays and hardening predictions retained.
