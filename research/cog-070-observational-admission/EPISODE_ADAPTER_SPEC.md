# 070 local CPU archive adapter and comparator recipe

This is an implementation design, not a trained model or measured result. Source ingress and support are unverified. No real episode or outcome view created. No reuse of 068’s 16-dimensional synthetic vectors, future availability, checkpoints, cutoffs, fitted values or labels. Only the causal three-lag, one-card, strict next-sample exceedance problem is shared.

## Exact interfaces

1. **Source intake**: require a frozen reviewed receipt containing role (`DESIGN_ONLY` for first stage), approved exact HTTPS origin and URI, scope times, three station and time-series IDs, reviewed publication/usage terms, operator/provider/datum/cadence, response SHA-256, response byte and row caps. Native adapter consumes local immutable imported files from that manifest, not network. Python 3.12 fixed schema rejects duplicate JSON keys, duplicate source observations and non-finite or non-numeric values. Read USGS decimal strings without float conversion during label construction. Use RFC 3339 UTC, right-exclusive frozen window, 900-second grid, role-specific file names and exact `time_series_id`, location ID, `00065`, measurement units, and approved/observed qualifier whitelist. Record all reasons before filtering. Neither missing measurements nor inferred timestamps are backfilled; do not use `last_modified` as original publication or knowledge time. Bounds: 36,000 raw data rows and 64 MiB total for admitted DESIGN check, three lanes per request, one CPU thread, 120 seconds for the support checker. First stage returns only support counts and DESIGN-derived threshold hashes, not episodes.
2. **Future offline episode (not authorized yet)**: `request={episode_id,scope:OPEN_PUBLIC_DEV_ARCHIVE,mode:EVENT_TIME_RECONSTRUCTION,block_id,cutoff_utc,lanes:[{station_id,series_id,datum_epoch,seen_event_times_utc:[t-1800,t-900,t],observations_ft:[v0,v1,v2]}]}`. Bound lane count to three. Validate occupancy and time/datum scope before reading numeric values. The declared historic archive revision pins accepted records; do not use future flags, approved status, availability or the mere existence of a `t+900` record to choose inputs, eligibility or advice. Record blocked-prefix reason rather than falling back to another time, location, or series. Derive deterministic IDs from the frozen roster hash and ISO UTC cutoff only, no label-derived ID. A performance method sees only the three normalized past values and approved static threshold context. Normalization is fixed from DESIGN (site-specific median/IQR, undefined IQR stops); no within-DEV transform fit. Exact chronological prefix and accepted eligible lane masks are shared among all arms.
3. **Evaluator-only**: `{episode_id,block_id,target_utc:t+900,lanes:[{station_id,series_id,status,publisher_record_hash,above_threshold}]}`. Separate scorer computes `value(t+900) > station_design_threshold`; if the target does not meet its prespecified USGS eligibility or cannot be matched, evaluator marks `UNEVALUABLE`, not false or success. Preserve the fraction and denominator of unevaluable records and compare results on exact matched cases; do not retroactively remove a card from the recommendation or cost ledger. Additional strata are first exceedance vs already above, station, archive flags and event block, not claims of independent storms. Hold the DEV label view separately and verify row/key parity only after dedicated score approval. Bind month/week wide blocks across all three lanes to address correlated weather; report event-rate and group support, not thousands of independent observations.
4. **Output**: `{episode_id,card_station_id|null,reason,predicted_not_observed:true,scope,policy_hash}`. One local read-only card or explicit abstention; ties broken by frozen ordered station IDs; serializer never reports observed/verified completion or takes action. Each baseline gets the same set of authorized candidate lanes. Separate independent locked scorer reports per-arm rejected prefixes, advice and abstentions, unevaluable targets, true/false cards, misses, one-card request-level correctness and all positive lane-opportunities. Count both matched advisory budget/coverage and total cost, not just conditional precision.

## Comparator and verification sequence

- Fixed null abstain; fixed latest normalized value interpreted relative to station threshold; cheap analytic persistence plus ridge CAL-frozen last-step slope to projected next height; and an input-matched single-thread raw-lag ridge/logistic over the same three past values if separately authorized. Admit a same-size projection only if independently justified and its own protocol passes: this one-sensor series offers three lag features, so 068's rank-4 encoder has no meaningful compression analogue and is **not** a control here. Do not pretend extra channels exist; exact/analytic replay is the sensible initial study. Trainable fit only through distinct TRAIN/CAL with model and iteration caps; matching contexts and fixed action count rule across policies.
- Software gate: test constructed rows for right-exclusive bounds, strict target cutoff, UTC/15-minute equality, no future row decoder at inference, missing or malformed prefix, datum transition, monotonic timestamps, deterministic tie/abstain rule, and byte-identical repeated model-input construction. Such tests verify software only and are not authentic samples. Native plan binds dependency/interpreter/source checks and explicit source role; Forge records input validation and grouped coverage, TrainLab stages native compute only after review, Veritas binds exact stage receipt and independent re-score. Never turn same-operator replay into outside replication.
- Compare against strongest cheap eligible baseline at matched frozen utility/advisory budget. Report paired whole-block uncertainty and both scientific and end-to-end inference cost, including validation and serialization; any future network wait stays separately measured. No model trial before exact approved scope, actual DESIGN supports, and reviewed newly frozen nonprotected DEV plan. No hidden research run, public response, live scheduling, release, spend or scientific qualification from this draft.
