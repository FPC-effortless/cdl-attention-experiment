# COG-LM-001 · causal language-model qualification cycle

Build a generative language model with a learned recurrent state, learned slot rewrites and relational reads, and an episodic successor index adapted from COG-099. Test whether the added memory changes held-out next-token loss and handles revised information. Predict every next subword with one shared vocabulary. Keep model parameters frozen during evaluation and scope inference state to one document. No tool actions, dialogue labels, oracle addresses or test-time fitting.

Train four arms from scratch on identical document windows with identical optimizers and update budgets within each panel. Compare a causal Transformer, the Apache-licensed Mamba-2 minimal reference (properly initialize its pretrained-only empty parameters), a COG recurrent backbone trained without the additional memory, and the full COG model. Use a small multi-seed panel (seeds 17, 29, 43; 256 × 512 targets/fit) and a 30–35M-parameter scale panel (seed 17; 128 × 512 targets/fit). Sequence length 128, tokenizer 2,048 byte-level BPE IDs trained on WikiText-2 raw train only. Freeze configuration and evaluate every arm at the final update. The scale panel tests actual training, generation and inference at this size; it is a short optimization run. Require a genuinely longer run or scale replication before any general capability claim.

Use official WikiText validation/test articles plus an out-of-domain MultiWOZ test transcript panel. Compare identical windows and bootstrap paired differences by document. Report reset and component-removal interventions on full weights, a no-fit-to-test lexical successor-mixture control calibrated on validation, and memory byte accounting. Test recall and revision with old and new token values and delays 64, 256 and 1024, including changed surface keys. Check parallel/streamed next-token parity, causality, closed document boundaries, cached generation and restart. Compare batch-one prefill and decode, with actual KV caching for the Transformer. Timing is for this CPU backend and budget.

Decision: a natural-text memory advantage needs lower held-out NLL than the separately trained backbone at all three small seeds, a document-bootstrap interval below zero on their mean, and consistent direction at 30M. Separate out-of-domain transfer, exact-match copying, revised facts, and practical inference cost. Report counterevidence. Reserve an LLM-quality claim for substantially trained models on a broader, independently held suite. This experiment implements a language adaptation of prior memory designs, not a claim that their original full agents were pretrained.
