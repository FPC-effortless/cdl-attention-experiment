# COG-EDGE v0.3 protected-state simplification (developmental)
Passive offline battery telemetry forecasting only. No vehicle control, deployment, safety or fleet qualification.

## Motivation
PR #106, run 46056420880, demonstrates that 16-second reset of protected state increases severe-outage 15-second development RMSE by 5.94%, vs 0.30% for predictive state; both 6.02%. 64-second effects 1.26% vs 0.04%. This is frozen-weight sensitivity, not a proof of removability. PR #107, run 46056593383, shows separate pooled coverage on held-out R 73.83%; pack-max 84.18% at width 0.27534 V vs pooled 0.20974 V. No uncertainty policy promoted. New experiment tests a narrower hypothesis: can the learned protected state retain forecasting quality without an independent recurrent predictive pathway?

## Frozen experimental arms and protocol
Five neural arms: unchanged COG (1914 parameters; 96 B raw recurrent state); protected-instant and dense-instant (each 1914 parameters, same initial weights as parent, replace predictive scan with its instantaneous input contribution, 64 B raw state); protected-compact (1306 parameters, removes predictive feature network entirely, 64 B); original static control (2286 parameters, 0 B neural state). All still use the same causal preprocessing, including last-known values; state bytes exclude it and runtime overhead.

Three original seeds 171/311/591, three original donor-training folds, 600 updates per fit, original 64-step windows, 16-window batches, loss, optimizer, learning rate and clipping. The pinned split file from PR #105 is unchanged: train only on original training flights, choose checkpoint using the separate selection subset, evaluate on the former calibration subset as developmental comparison. Do not score the old held-out-aircraft test subset. This is not a fresh external dataset; comparison set was previously used in prior studies. Never claim independent fleet generalization. All 45 fits are selected and saved before comparison panels are constructed in each fold. Same seed yields byte-identical training streams across all five arms, and parent/instant/dense-instant initial weight tensors match exactly. Retain actual parameter counts and wall-clock training time (not matched FLOPs).

Primary contrast: mean seed-and-fold 15s RMSE under 85% nominal missing observations plus simulated outages. Report all 12 regime/horizon cells, paired flight sufficient statistics, all seed/fold outcomes. Research screening only: compact/in­stant candidate must be within 2% relative RMSE of unchanged COG and not exceed 5% degradation on any donor-fold mean in the primary cell; additionally protected-instant versus dense-instant should show useful selective-state contribution rather than require forced gating. These are practical exploratory margins, not statistical equivalence, operational safety thresholds, or promotion gates. No test-set tuning. Uncertainty figures from uncalibrated heads are descriptive only; do not select a calibration policy.

Checks: all derived array identities and source manifest; partition disjointness; initial weight equality where applicable; training-stream hashes; 45 final optimizer/RNG continuations; all panel target counts; protected HOLD invariant, batch/step equivalence, prefix causality, and exact same-input hidden-state restart. Preserve all 135 original new checkpoints and results (including negative outcomes) in run-specific Git refs with SHA-256 manifests. No upstream raw telemetry redistribution until license verified.

After this screening, broad reliability still requires new independent equipment populations and calibration data; keep existing qualification HOLD. No architecture promotion based only on these developmental comparisons.
