# Reproduction and scope
The sources are frozen code. Regenerate only constructed inputs with sim.py using the pinned ecosystem integrations (integrations/forge/src, integrations/trainlab/src and integrations/research_lab/src on PYTHONPATH) and single-thread BLAS settings. RUNTIME.json pins the observed software identity. audit_generator.py independently reconstructs the simulated outcomes. test_preflight.py checks observed input boundaries; test_scoring_fixture.py uses temporary synthetic score fixtures only. No externally fetched dataset or designated TEST is needed.

Use stage-specific reviews for any future execution: fit with the generated TRAIN view only; prediction with pinned fit artifacts plus held observation/control view, excluding truth; score with the separately admitted truth and exact retained predictions. The convenience main in lab.py chains stages and was **not used** in the reported campaign. Fit, predict and score were executed once each with separately scoped exact approvals. No approval files or tokens, fitted checkpoints, observations, row-level forecasts, or per-group score files are included here. Inert plan checks and matching content hashes do not establish scientific qualification.
