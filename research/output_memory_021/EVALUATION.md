# OUTPUT-MEMORY-021 adapter scope (prefit)

No scientific fits or results are admitted by these adapters. The archived CSM conditioner learned literary next-byte prediction; it is not qualified for the six controlled task axes.

- Native features contain frozen values, links, cursor, and two-byte embedding history (392 coordinates). The decoder is trained separately.
- The separately supplied exact-state control parses external text through a fixed grammar. It exposes 16 canonical identity records with absent/value/reference tags, normalized three-byte payloads, reference identities, and the current query identity. Identity slots follow first textual appearance; query identity is parsed from the supplied question. 368 coordinates plus24 zeros give392 dimensions. No target is used. This is **engineered grammar, semantics, and identity binding**, not learned CSM. A decoder still must learn output rendering; this is not guaranteed perfect.
- TRAIN cache uses only TRAIN IDs. Features stop before each current answer. Earlier TRAIN gold answers are fed explicitly: teacher-prefix training has a free-running exposure mismatch and must not be described as on-policy training. Current/future targets are stored separately as labels.
- Evaluation streams all six query turns and feeds only generated attempted byte prefixes (including malformed/unterminated partial attempts) into native state. Gold answer regions are skipped. The exact executor consumes only externally supplied instructions, not generated responses. Boundaries are supplied to all arms.
- `zero` removes the entire conditioner feature; `swapped` exchanges the two paired features at each query. These are whole-conditioner interventions, not selective memory-only interventions: local history and query features are included. Sessions still ingest their own generated answers.
- Output capacity64 is fixed independent of actual target length. EOS is required for correctness; malformed/truncated output is failure. Raw tokens and bytes are retained. AR is KV-cached; diffusion uses K4/8/16. Stochastic streams are keyed by stable example/query IDs.
- Full pair wall time includes ingestion, generation, generated feedback, scoring and synchronization; excludes load and final output-file serialization. Conditioning/head subtotals do not sum to total (feedback and bookkeeping remain in total). CUDA peak is included. Cache build cost is separately retained training preparation, never hidden as free inference.
- All six020 DEV axes remain. Familiar finite grammar and held naming/wording/delay axes are not unrestricted real-language competence. No protected TEST or paid compute.
- Gates retain >=95% complete sessions and >=95% both-counterfactual-first-snapshot answers per axis/seed. Report paired group bootstrap uncertainty, each seed separately and all failures. Do not select favorable K after outcomes.

## Frozen answer format
Canonical targets are `The current code is ABC.` or `No code is currently assigned.`. Output capacity remains64 regardless of payload/answer length. Report exact sentence accuracy and independently extracted payload accuracy; the existing95% payload-session and both-snapshot pair gates remain. Invalid format, no EOS, or malformed output fails. Prior canonical generated sentences (not the original three-byte answers) enter the learned conditioner. TRAIN cache uses prior canonical gold sentences, explicitly a teacher-prefix distribution.

Cache schema: `features` float[N,392] native; `exact_features` float[N,392]; `targets` long[N,64] including EOS/PAD; stable `ids`; `bindings` with conditioner/source/data hashes, format and dimensions; elapsed preparation time. Only selected TRAIN examples may populate this cache. Development must recompute conditions along each head's own generated trajectory.

Five adapter tests cover fixed grammar/reference semantics across names/wordings/structures, current/future label mutation feature invariance, free-running feedback, mutation-resistant raw-token scoring, TRAIN-only rejection and rendering. These are software fixtures, not trained competence results. Cache and evaluation now batch independent ragged session streams; their total resource requirements must be measured before launch.

Feedback policy is always-feed-attempted-byte-prefix plus newline exactly once for all native output arms, including rejected/malformed/unterminated outputs. Such bytes affect only volatile learned history, never authoritative fact records. Do not call this accepted-output-only feedback. Batched wall time is whole-batch throughput, never fabricated individual latency. Scalar position advances through padding but is unused by admitted rewrite mode and excluded from features.

Each attempted output is followed immediately by one newline in native history. The dataset's next external chunk strips its corresponding leading separator, preventing double insertion. Bytes before EOS/PAD/invalid control are fed verbatim, without UTF8 replacement, even if output is rejected; no retries.

Prospectively frozen metric distinction: literal payload presence accepts exactly one standalone allowed uppercase/digit3-byte token, rejects multiple occurrences (even repeated identical tokens), and recognizes absence only via the canonical absence sentence. This is literal-field presence, not semantic answer correctness: negation could contain that token. Full-sentence exact session accuracy >=95% is additionally mandatory per seed/axis, alongside payload-session and both-counterfactual-snapshot gates. Literal presence cannot independently qualify a candidate.
