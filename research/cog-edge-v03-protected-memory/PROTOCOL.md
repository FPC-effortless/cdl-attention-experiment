# COG-EDGE v0.3: protected-memory simplification and training robustness
Status: frozen developmental protocol, not qualification. Passive battery telemetry, no navigation, flight control, or safety deployment claim.

## Motivation and controlled design
PR #106 indicates the protected state contributes most of the measured reset sensitivity (16s protected +5.94%, predictive +0.30%, both +6.02% RMSE on development data). PR #107 shows aircraft R severe 15s pack-max coverage 84.18%, despite interval width .27534 V (pooled .20974 V); high last-observed-current strata have large errors. These observed results motivate the experiment; not a new blinded cohort.

Full 2x2x2 factorial: selective vs dense observation banks; recurrent vs current-input-only predictive pathway; standard vs fixed weighted Gaussian NLL. All eight models have exactly 1914 parameters, identical initial model hash and training batches within each fold/seed. Local pathway uses the same learned dynamic coefficients but outputs the current contribution only (no previous predictive state); protected state has 16 FP32 coordinates, recurrent models have 24. All weights remain trainable. Same original training windows, 600 updates, three seeds, three folds (72 planned fits), optimizer, clipping, selection criterion. Fixed weighted loss multiplies target NLL by 1 + .5 I(voltage observation age >=16 seconds) + .5 I(last-observed current >= training-only upper tercile), normalized over scored targets; no test or contemporaneous unobserved current. No other hyperparameter search.

Use v0.2 four-way partitions, original train and selection subsets. Evaluate once on the prior calibration subset as a **development diagnostic**, after all eight arms and three seeds are fitted in each fold. Do not construct test input panels, read test labels for scores, or calibrate from test. Test files are only reconstructed/hash-verified for custody. No fresh aircraft/generalization claim; calibration subset has been used in earlier work. Report uncalibrated nominal Gaussian coverage/width as diagnostic only, not coverage guarantee. Primary descriptive comparison: severe 15-second RMSE, all 12 condition/horizon cells, voltage-observation-age and last-known-current strata, equal seed/fold aggregation. Assess the three factors and interactions, and compare RMSE, NLL, bias and width jointly. No policy is promoted by results on this cohort.
