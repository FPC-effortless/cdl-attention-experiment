# LIFECYCLE-LEARNING-001 — supervised mechanism feasibility

14 November 2026. Prospective, bounded development diagnostic. The question is whether an unchanged CSM record-rewrite backbone and a conventional pointer-capable slot control can learn five one-hop lifecycle mechanisms under the same process supervision. This is not the admitted cross-architecture benchmark: the old MEMORY-FAMILIES-046 / TEMPLATE-SPLIT-047 failures and 30-component floors remain unchanged. No old private corpus, hidden TEST, architectural ranking, significance claim, paid compute or inference-cost claim.

## Design and falsifiers

Five known templates: overwrite; query during source absence; copy a directly absent root then recreate it; detach an alias by overwriting it; delete an alias. Every template includes a paired COPY/LINK assignment and queries all four records. Source roots, alias, snapshot and unrelated-record roles are permuted; four distinct values are sampled from eight. A COPY snapshots a root only; LINK points to a root only. QUERY may follow one live pointer. No COPY-through-alias, multi-hop chains or cycles are in scope. Every DELETE/recreate example must retain an absence-sensitive snapshot query. Full-map correctness and mechanism-specific outcomes matter more than overall accuracy.

Generate exactly128 unique role/value assignments using seed140011, fixed before fitting; each assignment yields all5 templates ×2 focal operations ×4 queries. Release with one frozen Forge salt and subject grouping by assignment, unioning assignments transitively when they share an identical event history (unused values can otherwise leak literal streams). All templates occur in both selected TRAIN and validation: this tests learning/interpolation on known templates, not independent causal-template generalization. Renamed/value-varied examples are not independent mechanisms. Do not resample source or salt after seeing fit/validation performance. Only use TRAIN for optimization and validation after every fit has closed. Forge's third bucket is not exported/scored. Report all assignments and template counts explicitly.

Both models see the same raw three-token operation grammar, padded to8 events, followed by a three-token query. Physical roles/targets are not inputs. During training only, supervise first source, direct second address, destination, use-link, value-edit, link-edit and full-overwrite gain, equally for both models. Mask irrelevant addresses on noncommit tokens, direct-second labels on linked queries and gain where no value write occurs. No operator labels. Noncommit edits are zero; address heads are unconstrained. QUERY learns to write its answer into reserved scratch slot7; user records occupy slots0–3. This interface is constrained and does not establish general CSM semantics.

CSM uses the unchanged recovered `RecordRewrite` architecture (width32,8slots,4operators,transformhidden64). Hooks only observe heads during training. The control adds source reads and one pointer row per record to the old slot design; it removes CSM's state-conditioned controller and operator bank, using a wider transform(hidden98) to match total parameters. This wider nonlinear layer is a tradeoff, not identical transform capacity. Neither arm receives a perfect parser, test routes or hidden-state values at normal evaluation. Both use hard forward decisions with straight-through softmax gradients.

## Fixed training and analysis

Two arms ×seeds101/202/303,512updates each,batch32,AdamW lr0.002,weight_decay0.01,clipnorm1. One CPU thread per process, sequential runs, max180seconds per fit. Same seed-specific sampling schedule and supervision/loss weights. All weights initialized fresh; no checkpoint selection or extension after inspecting results. Answer CE plus each relevant categorical-head CE and0.25gain BCE. No auxiliary answer labels at intermediate tokens. Preserve every loss, checkpoint and attempt. Stop on nonfinite values or failed verification, retaining failure. Maximum6 fits and98,304 answer exposures.

Primary descriptive outcome: final-query accuracy and complete four-query maps, separately per template, focal operation and seed. Record critical outcomes: alias answer, absence snapshot, preservation of unrelated record, detachment and alias deletion. Report seed results individually; do not pool correlated rows into an IID confidence interval. A95% per-template threshold in every seed is only a predeclared development screen, not qualification.

After all fits close, evaluate normal raw-token inference, values-erased-before-query, identity-links-before-query, and supplied-control diagnostic inference. Supplied controls are a privileged failure-localization condition and may not be reported as learned success. Check exact preservation of user-slot values/pointers before and after each query. Four-query complete maps replay the history separately for each query; they do not alone establish sequential-query safety. Normal head accuracies separate control failures from learned value-transform failures. No timing ranking; TrainLab wall time includes training/initialization.

Use existing Forge, TrainLab, Veritas and Research Lab interfaces only. Research source and trained artifacts belong to this experiment; no ecosystem implementation changes. Independent prefit review must verify model representability, training-information parity, deterministic semantic oracle labels, routing parity with original CSM, pair contrasts, absence relevance, and freeze before optimizer steps. Postfit independent review checks saved evidence and interpretation. A negative outcome is retained without repairing/retraining within this protocol.
