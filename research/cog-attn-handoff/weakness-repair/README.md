## WR-001: credit assignment and compositional grounding
Three seeds 11,29,47; 4096 training examples/seed, 400 Adam steps, 64 batch, fixed final checkpoint. Eight entities with independently permuted 16 aliases, four directional markers, four seen operation words, two unseen words. State is eight integers mod 4. True transition copies source to destination or adds source to destination mod 4. Pair holdout is `(source+destination)%4==0`, excluded from training. Recombination crosses seen verb style and marker style. Familiar and test cases drawn independently. Synonymous surface forms represented by supplied alias/marker/verb IDs (not learned span detection). Factor model learns alias distributions, role direction and operation distributions. Probability over 128 candidate actions computed by factorization. Soft loss sums probability of all actions that produce observed final state. Gold uses true action; hard uses first compatible candidate, an intentionally simple diagnostic rather than strongest pseudo-label algorithm. Flat model uses embeddings and MLP. Parameter counts 144 vs 12304, not capacity-matched. Three fits per model (12 total); no hyperparameter sweep. Exact state accuracy per 3072 cases:

| Arm | familiar | held pairs | recombined | novel verb |
|---|---:|---:|---:|---:|
| factor soft |3072|3072|3072|1538|
| factor hard |1801|1741|1718|1422|
| factor gold |3072|3072|3072|1538|
| flat soft |3072|693|3072|1731|

The factorized soft model passes the bounded gates and achieves exact action accuracy on all known-cue cohorts; flat does not generalize to held pairs. Novel verb accuracy unqualified; unseen embeddings randomly initialized, and synonymous mapping not identifiable without prior or feedback. Outcomes can be ambiguous or no-ops; no direct action labels for soft loss, but action space and exact executor supplied. Enumerating all actions is potentially expensive at scale.

## WR-002: new word acquisition, clarification and compiled decision path

Active sets destination nonzero so copy and add differ; passive samples all states uniformly. Equal maximum budgets, stopping at posterior >=.95, known binary noise likelihood and independent corruption. Clean one observation: passive 6137/8192 admitted, all correct; active 8192/8192. At 10% noise, max 7: passive correct prediction 8029, admitted 7918, admitted correct 7816, 26276 observations; active 8094, 8144, 8054, 19866. Wrong high-confidence admissions remain (90 active); not a guarantee. This simulation assumes correct entity binding and known operation family, and is separate from neural novel-verb evaluation.

Three factor-soft checkpoints compile argmax alias and verb tables and role-score comparisons; all 12288 fresh known-cue determinations match neural predictions. Explicitly remove verb/role cues in a separate simulated clarification test; enumerate two operations x two directions. Ask when consequences differ using learned entity IDs. Ground-truth ambiguity 11522/12288, ask 11522, unsafe misses 0, extra 0; default copy in mention order gives 7561 incorrect state outcomes. The simulator supplies complete missing cues when asked; no trained question generation or spontaneous ambiguity recognition. All final outcomes match. CPU median per seed, batch 1 and 256 in followup.json; compilation cost separately measured, raw feature encoding omitted. Hard compiled decision does not preserve full posterior; verification and escalation not timed. Only tested on known cues, no general exact argmax theorem for factor mixtures.

## WR-003: episodic memory
64 seeds (100–131,300–331), 32 entities, 4096 events per seed, 15% late records with valid time in past, 256 random queries per seed. Event valid time differs from arrival/transaction time. Query chooses maximum `(valid_time, tx_time)` satisfying both cutoffs. Current view and per-entity sorted history with predecessor search and backwards visibility check. Latest-only 153/16384 historical queries; indexed 16384/16384, 2048/2048 current queries. Full history scan 3500.88ms total, indexed query 11.22ms + 93.22ms prep, 33.52x amortized over tested workload. Full scan already has generated log; input generation excluded both. Payload estimates 32 bytes/event plain log; 24 bytes/event indexed with implicit entity plus 24 bytes/current record, excluding lists/object overhead. This does not compress arbitrary history into constant memory; grows O(events). Query worst case linear in entity history for old transaction cutoff. Additional stress 8 fresh seeds per length 128,2048,32768; 75% writes to single hot entity, 30% late insertions, independent cutoffs, 512 queries per length. All exact, max candidate checks 91/1393/22159 respectively; aggregate timings in audit.json. Consider persistent two-dimensional range index for adversarial historical queries; current index not guaranteed logarithmic in both dimensions. Late correction semantics here are append-only event updates, not general truth/source invalidation.
