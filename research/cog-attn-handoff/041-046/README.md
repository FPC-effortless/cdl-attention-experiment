### 041: paired residual grouping
Seven binary sensors, three independent errors .04/.09/.12, four copies of the shared latent signal (latent inversion probability .92, or .72 in mild condition, separate .10 copy error, .01 in near-duplicate condition). For 512 calibration states, compare raw agreement >.95, repeated reading with the same latent nuisance, and an intervention resampling the latent nuisance while holding true state fixed. Group connected components with difference correlation >.25, then use grouped unlabeled EM on the original readings. No truth labels used for grouping. In weak-copy condition the intervention correctly recovers the group structure 63/64 worlds; accuracy 32308/32768 = 98.60% vs raw 1921/32768 = 5.86%, same as passive repeat. Primary 16180/16384, replication 16128/16384. Majority 33.15%. Near duplicate raw and reset both 98.85%; mild raw 26.66%, reset 98.04%. Unmodifiable nuisance raw/reset 6.10%; the mechanism requires a reset that changes the shared nuisance without changing the target. The grouping metric detects the simulated dependence under this intervention; does not establish arbitrary causal structure or general identifiability.

### 042: orientation, admission and drift
Equal prior over the two possible global orientations; update orientation odds with 0/1/3/7/15 known-outcome anchors, using likelihood from the fitted latent predictor. Predict by posterior mixture and admit confidence >=.95. No anchors yields .5 predictions and zero admissions. In stationary weak-copy condition 3 or 7 anchors: 32308/32768 correct, 31281 admitted, 31222 correct admissions (99.81% precision, 95.46% coverage). Brier .0103 and ECE .0086 (mean seed-level confidence binned calibration estimates, descriptive only). In global inversion: 403/32768 correct before orientation, 32365/32768 after 3 or 7 anchors, 31279 admitted, 31219 correct (99.81% precision, 95.46% coverage). One anchor gives 92.36% coverage and 99.82% precision. Under fixed unmodifiable nuisance even seven anchors only 93.90% accuracy, 97.35% admission precision (fails gate). Unannounced inversion after calibration gives 444/32768 correct in weak-copy condition with stale 7-anchor model, ~95.43% coverage. Fresh-window followup on disjoint 32 seeds: stale 230/16384, fresh 1/3/7 anchors 16154/16384; 3-anchor admission precision ~99.80%, coverage 95.48%. Scheduled refreshing is supplied, not autonomous change detection; confidence and source grouping still rely on model assumptions. The original orientation model is not a proof of independence. Anchors are supplied known outcomes and their physical acquisition cost not modeled.

### 043: operator-family expansion
Unknown maps over two coordinates in finite field F7, from all 49 inputs. Fit 20, validate on disjoint 8, hold out remaining 21. Enumerate feature degrees 1,2,3 (not whole operators); perform exact modular linear algebra, expand if inconsistent or fails validation. 512 maps per family: affine, quadratic, cubic each all 512 admitted, all 10752 test states correct. Affine-only control matches affine and rejects all quadratic/cubic. Random lookup 0/512 admitted, 0/512 for one corrupt training component in same exact solver. Followup 512 maps per regime with three repeated observations and plurality decode: isolated single corrupted read all correct; independent .12 component error 148/512 admitted and 3108/10752 exact (all admitted operators correct); correlated +1 mod 7 on first output in training AND validation admits 512/512 wrong maps and yields 0/10752 true predictions. Shared-bias test demonstrates observational consistency is not truth. Operator family and underlying feature map supplied; not arbitrary program discovery. No full lookup expansion claimed for unseen inputs.

### 045: factor discovery (exploratory negative)
Random 2–4 factors each with five anonymous token values, unordered observations one value per factor, additive modular outcomes. Learner uses absence of observed cooccurrence, connected components and internal clique/one-per-group consistency checks, then solves effects with gauge constraints; gold grouping only used for evaluation. Distinct environments per budget, not paired learning curves. At nominal 20 and 60 observations no correct groupings or admissions, zero unseen predictions (5360 and 7660 respective evaluation states). At nominal 100, 10/32 groupings and admissions, 750/3980 held-out predictions (18.84%); true groups not supplied. Budgets capped by domain size minus 5. Missing cooccurrence is not evidence of exclusion; more principled factor estimation needed. Does not discover hierarchies.

### 046: multistep cost-aware curiosity (exploratory)
Known independent sensor error .25/.05, cost 1/4, horizon 8, error penalty 30. DP minimizes acquisition cost + penalty for terminal prediction error. 16384 simulated trials per arm: cheap-only optimal stopping 88.90% accuracy, mean cost 3.0737, penalized loss 6.4025; expensive-only, one-step greedy cost-aware, and full DP all identical 95.20%, cost 4, penalized loss 5.4392. No advantage of DP in original regime. Compiled DP cache preprocessing ~0.508 ms on this machine across three allowed action sets; timing details in followup.json. Analytic cost grid (6 costs x 5 penalties, 30 regimes, known model, no empirical test labels): mixed DP strictly improves over either single-sensor optimal policy in 12/30 regimes. Largest tested advantage at expensive cost 8 / error penalty 100: expected loss 9.88867 vs best single-sensor 11.94531 (17.22% reduction). Values are exact finite-horizon model expectations to floating tolerance, not an observed real-world learned policy. The grid is exploratory and not a comparison to mixed greedy in every regime. Under model misspecification guarantees need not hold.
