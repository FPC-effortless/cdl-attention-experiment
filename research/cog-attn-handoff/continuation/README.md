# COG-ATTN continuation evidence

This index covers the 15 evidence bundles available from WR-004 through the 047–050 qualification and follow-up. The complete local bundles are [GitHub Release assets](https://github.com/FPC-effortless/cdl-attention-experiment/releases/tag/cog-attn-continuation-20261120). They retain the recorded protocols, results, audits, checkpoints, run receipts and negative findings included in each original bundle. The files in this branch provide browsable reports and entry scripts. Use an extracted bundle to replay the experiment with its inputs.

## Integrity

[Evidence manifest](evidence-manifest.json) records the byte length, SHA-256 hash and archive file count of each bundle. [SHA256SUMS](SHA256SUMS) verifies downloaded archives with `sha256sum -c SHA256SUMS`. [Source manifest](SOURCE_SHA256SUMS) records the hashes of the browsable copies. Archive directory layouts vary and match the original deliveries.

## Coverage boundary

The parent handoff preserves the reports and protocols for COG-ATTN-001–046, both lifecycle cycles and WR-001–003. Its [archive manifest](../ARCHIVE_SHA256SUMS) lists ten older binary archives. Those archive bytes were unavailable in the workspace used for this release. Historical reports and the earlier checksums remain on the branch. The separate [LRC frozen repair release](https://github.com/FPC-effortless/cdl-attention-experiment/releases/tag/lrc-route-repair-002-20261108) has the upstream LRC artifacts.

Publication preserves evidence and the qualification status stated in the individual reports. The scoped CPU comparison and typed replacement bridge passed their stated gates. Authentic update recall, full original TAC recovery, independent external authority, accelerator and cross-host qualification remain open.
