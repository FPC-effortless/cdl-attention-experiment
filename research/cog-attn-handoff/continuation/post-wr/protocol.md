# Post-WR comparison protocol

Reuse the WR-010 workload and three frozen teachers. Train one single-block causal Transformer per teacher by regressing its source/destination/operation logits on the original 4096 training commands. Use the same unigram/bigram token IDs. Freeze the student after 1200 Adam updates; evaluate on independent 1024-command samples from familiar, held-pair, recombination and novel-verb cohorts. Require raw action accuracy within 2 percentage points in each pooled cohort. Use a shared confidence gate (0.80); separately require assisted read accuracy within 1 point and clarification fraction within 5 points at workload level before interpreting matched latency. Always report unmet gates. KV inference must match full attention logits on held-out commands.

Compare WR-010 blocking clarification with staging below 0.995 and a confirm-all upper bound. Staged writes remain private until verified; process commands serially so ordering is preserved. Apply both model families to the four prior write mixes with the same lazy answer cache and semantic memoization. Compare 0.80 versus 0.995 within model; stage/confirm-all on the WR model. Charge elapsed request/reply time for every clarification with an actual separate local service, explicitly distinguished from human or WAN latency. Use the same truthful responder and no injected sleep. Preserve model errors, asks, timings, raw predictions and per-case verification. This is a warm-process, batch-one CPU comparison with no distributed-state claims.

The initial fixed-step logit-MSE student failed the validation gate. Preserve its checkpoints and results. Before evaluating another student, change the objective to temperature-2 factor-wise KL, initialize the query projection at zero and train 2200 steps at .002. Reuse the earlier validation slice for diagnosis and check final competence on an additional fresh slice before drawing a matched comparison.

The KL student still missed the held-pair and novel-verb gates. For a function-matched latency control initialize the Transformer value path with the teacher embedding tables, near-uniform causal attention and a small residual feedforward projection. Fine-tune all parameters on the original training commands for 300 MSE steps at 1e-5. Use previously unexamined seed offsets 52000 for final validation, unchanged gates and unchanged workload. Treat this arm only as a teacher-initialized implementation comparison. Freeze the KL student separately for reporting.

The strict stage gate in the paired workload requested confirmation on every write. As a post-hoc follow-up, test both matched model families at 0.995 with confirmed exact strings memoized through each workload. The experiment assumes one stable semantic epoch and a truthful responder. Require preserved gold-state read accuracy and fewer requests compared with the nonmemoized strict gate.
