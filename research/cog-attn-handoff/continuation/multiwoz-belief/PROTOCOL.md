No future utterances, gold prior states, auxiliary dialogue acts, or reply oracle. Each dialogue starts empty.

Keep all verified commit IDs and values identical to the gated baseline. Separate a read-only provisional distribution from the SQLite commit interface. Consequential consumers can read only the verified store. Test isolation, dialogue reset, mixed two-slot turns and an authoritative override. A high score is model-admitted evidence; human confirmation is absent.

Compare against unrestricted carry separately.
