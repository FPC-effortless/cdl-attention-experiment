# Real GitHub issue histories

Record of the design before held-out scoring. `recipe/design.json` fixes repositories, calendar intervals, observation cutoffs, cohort cap, horizon and statistical gates. Acquisition starts before model fitting, using the earliest qualifying issues per repository and calendar interval. The search filter is public issues with at least one comment at collection time. This cohort is a sample of commented issues, selected from five Python scientific projects with an early-in-window cap. It excludes PRs and is not a random sample of GitHub activity. Repository membership is frozen by design. SymPy is unseen in training and threshold selection. The recurring-repository holdout and the SymPy holdout are always reported separately. Resampling is by issue, not by individual comment.

## Behavioral target

In historical replay, each unedited human comment is an opportunity to propose the only legal state transition from the visible issue state. The competing action is defer. Gold positives are observed issue close/reopen events by the *same actor* within 15 minutes, strictly after the comment and before the next human comment. The first state event ends the search, including if performed by a different actor. This is a behavioral proxy and does not establish author intent, comment causality, historical permissions or current authorization. Actor IDs are used for within-issue equality and label linkage, with no actor identity supplied to learned models. The observed comment order used is GitHub timeline order. Skip empty/edited/deleted-user/bot comments, any candidate that shares a timestamp with a state event or other human comment, and candidates with incomplete right-horizon follow-up. Edited human comments can still end a label search. If observed state events do not alternate from creation or the recorded events are out of order, exclude the full issue from label construction and report the issue count. Exact cache identity replaces handles, URLs, code blocks, numbers and whitespace with shared forms. A separate sensitivity adds same-second comments if followed by the relevant event in server order. Final snapshot agreement compares the full collected timeline to the state field returned from search and is reported separately from strict pre-comment state. Neither downstream state nor future events are used as feature input.

## Systems and learning

Replay recorded state events through the prior SQLite WAL commit core and the WR-006 predecessor tree, with pre-comment queries scored against a separate prefix oracle and latest snapshot cross-checks. Use a single event ordinal for both index coordinates since original ingestion timestamps are unavailable. The systems subtest measures execution and event-time history conditional on a complete ordered stream.

Supervised references include always defer, train prevalence, a prior-only logistic regression, a tuned word/character TF-IDF logistic regression, and a stronger flat logistic regression combining the same text, safe history, NLI and explicit cue features as the modular arm. The modular policy uses cross-fitted separate text and history predictors, a local pinned NLI model scored against the currently legal effect, and an explicit cue channel. The frozen policy can require a second channel at admission. Exact normalized binding reuse is an ablation with at least three distinct training issues and unanimous outcomes, conditional on valid state and past actor action status. This cache is evidence of repeated behavior, without authority attestations. A provenance-aware staging boundary leaves unsupported predictions uncommitted. All observed state mutations are historical GitHub actions replayed on a local copy. No GitHub issue mutations.

Regularization and all admission thresholds are selected on the 2025 validation partition only. From a fixed probability threshold grid and optional NLI/cue corroboration grid, select the maximum positive recall that meets 99% empirical validation precision. If there is no qualifying nonempty policy, defer all. Report scores on both held-outs, including average precision, ROC AUC, Brier loss, precision-recall frontier, false proposals, positive recall, comment coverage and exact versus unseen text performance. Report paired issue-cluster bootstrap intervals for test AP differences and an exact one-sided 95% binomial lower bound using distinct admitted issues as units, counting an issue with any erroneous admission as a failure. The exact bound assumes independent issue units, which may be optimistic for repeated actors and templates. Three Lab seeds change grouped cross-fitting folds, not the corpus. Do not count those runs as independent corpus replications.

The main gate is at least 70% recall of observed positive comment-transition pairs at at least 99% point precision and a one-sided 95% lower bound of 99% on issue-level error-free admission, separately on each held-out cohort. Zero admissions fail the gate. A precision-constrained ranking or later threshold sweep can diagnose separation but cannot qualify the held-out policy. Report close/reopen counts separately, and behavioral false negatives from the label design as a limitation. Systems replay expects exact agreement with the independent oracle and reports coverage, state discrepancies, and latest-state cross-checks. No performance qualification from unmatched model competence or single node replay.
