# Weakness repair program

Use fresh seeds 321, 337 and 353. Freeze inputs in Research Lab OS before execution. Keep the endpoints distinct.

- Grounding and credit assignment. Compare a contextual pointer with an independently initialized Transformer pointer on the same constructed inventory language, data, consequence marginalization, optimizer and step count. Test familiar syntax, held syntax, unfamiliar verb phrases, both changes together and ambiguous or unsupported instructions. Generate a separate 96-transition support set for novel language adaptation. Report action and effect accuracy, ambiguity, calibration coverage/precision and checkpoint/CPU process memory. Require at least 90% committed precision at 70% coverage on held syntax and within five percentage points held-syntax effect accuracy for competence-matched timing conclusions. Test support-based adaptation without consuming held-out commands. Neither system receives gold action labels during training. Small constructed language is an intermediate gate toward unrestricted grounding.
- Silent shift and operator discovery. Compare event-only checks, periodic known-outcome anchors and the same periodic schedule with intervention-backed anchors. Randomize shift onset independently of the schedule. Count wrong admissions, delay and audit cost with independent versus compromised anchor channels. An audit every 32 accepted commands is the fixed budget. Test finite program synthesis with shared-bias validation versus independent interventions on a finite input grid. Include random tables and unexplored cells to expose the boundary of the hypothesis class.
- Concurrency and history. Run actual concurrent local clients against SQLite WAL with two authority dependencies and compare separate check/commit to atomic transaction validation. Use synchronized race barriers and competing writes with idempotency keys. Verify independent replay and revisions under valid and transaction cutoffs. Compare point-in-time query costs and real allocated footprint with a full index, a checkpoint plus retained history window, and a full scan. Report process peak RSS and storage bytes with their scope. No cross-host or consensus claims.
