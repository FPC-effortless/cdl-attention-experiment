# WR-008 authority and precedence follow-up

On two public CompanyWorld task types, the candidate hashes the first record matching the public task's required source type and object ID. It compares that fingerprint with the one captured when the answer was cached. The control hashes the records cited by the cached answer. Inputs use fresh seeds 101, 113 and 127 with 48 paired cases per seed. Each mutation starts separately from a populated cache.

The candidate met the frozen 20-point effect threshold on every seed (87.5% versus 62.5%). On the hidden override even fresh evaluation failed. Public precedence follows input order in this fixture. Real temporal or jurisdictional authority would need a reliable observable contract. This experiment uses a scripted solver and fixed source-type mapping.

In an exploratory randomized-order warm-hit microbenchmark, median microseconds per guarded/fresh call were 4.14/3.06 with two records, 4.72/3.80 with 32 extra distractors and 8.30/8.91 with 256 extra. These measure local lookup and hashing versus executing the scripted policy on an already available public payload. They exclude cache population, misses, verification, and end-to-end runtime overhead.

Research Lab OS registered the protocol and research memory. TrainLab ran six cells. The same-host audit checked six receipts, reconstructed the fixture inputs from fixed seeds and rescored all 2,304 saved submissions using CompanyWorld. It shares the fixture generator with training-free evaluation. Forge participates in the separate ecosystem reference comparison. The custom inputs are generated by the registered recipe. No independent review or full runtime qualification was performed.

## Reproduction

Use Python 3.12 and install the four ecosystem packages at Veritas commit eec439492407b0aa26922c23b5ae40d95289f4eb. From a fresh directory containing launch.py, audit.py, timing.py and recipe/cache_trial.py, run:

    veritas-ecosystem run "$PWD/ecosystem"
    python launch.py
    python audit.py
    python timing.py
    veritas-ecosystem verify "$PWD/ecosystem"

The bundle includes frozen recipes, per-case submissions, receipts, database, timing samples and audit results.
