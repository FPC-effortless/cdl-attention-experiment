Scope: 64 primary/replication seeds (12000–12031, 13000–13031), 64 fresh exploratory follow-up seeds (14000–14063), and 64 fresh source-routine bridge seeds (15000–15063). These experiments extend COG-ATTN-041–046; 047–050 have NOT been run. The protocol predates the primary run. Followups are exploratory, not retroactive gate changes. ## 042b — shift detection
Three noisy binary channels (independent .02/.08/.12 errors) and rare outcomes (5% of commands, .01 error). Initial calibrated orientation supplied. Each seed has 1000 commands. Nonstationary stream has one uniform shift in [250,750); visible feedback stays truthful, silent feedback shares inversion. Event checks trigger on at least 2 mismatching outcomes in 64 commands or 9 disagreements in 16, with 16 command cooldown. Periodic checks every 64 commands since last anchor. Hybrid is the union. A known ground truth anchor compared with noisy majority vote can trigger quarantine; next three anchored votes set orientation. Only unanimous and non-quarantined samples admitted. False alarms, admissions, precision, timestamps (relative delay) and counts in results.json. Median delay conditional on detection, never impute misses. Detection defined as first quarantine after shift, repair independently measured. 

Visible event detects 64/64 eventually, 61/64 within 80; median 28, precision 96.40%, 4.83 anchors/1000. Silent event detects 14/64 eventually, 3/64 within 80; median 187, precision 58.14%, 4.84 anchors/1000. Periodic detects 63/64 within 80 in each condition, median 34, precision 96.59%, 19.56 anchors. Hybrid visible detects 64/64 within 80, median 16.5, precision 97.92%, 20.05 anchors; silent 63/64, median 32, precision 96.52%, 36.91 anchors. Stationary all policies about 99.98% admission precision but about 79.4% coverage; event 1.05 anchors/1000. Hybrid silently biased outcomes keep disagreeing after repair, causing excess checks. No policy meets all prespecified gates. A symmetric prior and equally distributed true bits make silent inversion observationally indistinguishable absent independent anchors; this is a constructed identifiability limitation, not proof every real shift is undetectable.

Fresh 64 seeds, frequency sweep 4/8/16/32/64/128: precision 99.85/99.70/99.25/98.30/96.36/92.96%; mean anchors 260.27/132.05/68.17/36.22/19.56/11.38; coverage 78.82–79.32%. Tradeoff unresolved. No physical anchor costs modeled.

## 042c — selective invalidation
16 sources and 4080 synthetic derived record nodes; topologically ordered DAG, domain-local parents and rare cross-domain dependencies. 12 shifts per seed, sometimes two sources. Source epoch increments; descendants must quarantine until trusted source is revalidated (provided) and dependent records rebuilt. Full forward scan is independent oracle for affected set, full forward value recomputation verifies all nonstale records. Reverse propagation matches affected set on 768/768 changes, no unrelated invalidation or stale read with complete graph. Attempted reverse-order repair blocks nodes with stale parents; topological rebuild yields exact parity. Average affected 431.33/4096, preserved 3664.67. Mean edge checks 548.81 vs 5485.37; average prepared propagation 82.34 us vs 424.33 us (exploratory Python CPU). Reverse index preparation 864.90 us/world. Timings isolate traversal; do not claim full repair speedup. Negative control omits one direct reverse edge: mismatch in all 768 events.

Followup: independent cached transitive source masks from forward edges, single changed source starting from original snapshot; 16 per seed. In 1024 tests, missing reverse edge leaves 100321 cumulative affected-node instances unquarantined. Guard using independently preserved masks blocks all, 0 unrelated blocks. If same omitted dependency corrupts forward provenance too, all 100321 leaks return. This is not a guarantee under arbitrary incomplete provenance. The bitmask represents dependencies, not a production implementation of per-source version snapshots; the separate bridge tests epoch stamps.

Source-routine bridge: 64 fresh seeds, 128 records per seed, 16 source values. Original LRC BoundedKeyIndex (two candidates per bucket), original CSM trace induction and execution (swap/identity). Both upstream Git blob hashes verified: upstream_lrc.py 9be6701d7d331e6849b2539db202de971b3e5c01 (cdl-attention-experiment research/lrc-route-repair-002-20261108 experiments/lrc_route_repair/index.py); upstream_csm.py b0d4dd35495dcaa06837d5d3181c29cd77e09061 (commit 2a3dd21fcbd55e87eca3c4e5bb05846136b86d4f research/csm-bdh002-handoff/skill001/pilot.py). ## 045b — active conceptual factor discovery
Unknown partition of 10/15/20 anonymous symbols into factors of five; counts and sizes not supplied to learner. Feasible pair means different factors; infeasible same factor (known model assumption). Active probes compare each symbol to group representatives, union compatible-with-same-factor evidence (infeasible pairs), record cross-group compatible evidence. Certificate requires observed same-factor connections within groups and explicit different-factor witness between each pair of groups. Clean certificate logically unique conditional on exact pair oracle and partition assumption. 64/64 exact certified at 30.625 logical tests mean, exhaustive 121.875, random same per-world budget 1/64. Passive positive-only no certified exact groups; naive absence heuristic yields 0/64 at 20 scenes, 2/64 at 60, 14/64 at 100. Scene and pair-test costs not equivalent. 

Independent .10 pair error: 1/3/7 repeats per comparison yield 7/27/59 exact groupings out of 64, all internally certified (certificate is not statistical truth). Independent seven-read validation of group member ties and cross-group representatives rejects all wrong with 6/27/52 correct certified respectively; mean total reads 156.92/209.55/326.92; no repair on rejection. Fresh 64 seed exploratory sequential log-odds test: accumulate +1/-1 per observation (equal prior, known 10% symmetric noise), stop at absolute threshold 3/4/5 or 31 reads, abstain if unresolved. 63/64, 64/64, 64/64 exact certified; mean reads 109.38/145.56/183.22. No independent confirmation in sequential arm; finite sample zero errors is not proof of reliability. Shared bias, overlapping factors, unknown compatibility semantics, hierarchies and real-world interventions untested. No learned hierarchy claimed.
