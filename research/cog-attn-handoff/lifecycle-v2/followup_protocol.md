At 32 audits/1000 compare a deadline policy prioritizing oldest source once age reaches 375, and half round-robin / half risk allocation. Report actual maximum age, not a claimed hard bound. Repeated-read race: compare last-read epoch overwrite vs first-read or explicit conflict detection on 128 repeated reads per seed; demonstrate the need for atomic commit, but no actual multithreaded proof. Coalescing: 8 single-key updates before each of 16 queries, compare eager per-update repair, batched repair before query and full rebuild before query; preparation and actual query time excluded, equal final root checks.
