# COG-ATTN-001 — engineered cognitive integration pilot
Date: 2026-11-20. Local experiment; no repository publication.

## Run
Python 3 and NumPy. Run from this directory:

```
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python pilot.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python audit.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python timing.py
```
`results.json` contains complete per-seed outcome counts and scaling measurements; `swaps.json` contains additional reader and association controls; `timings.json` contains prepared full-query timings. `audit.log` records deterministic replay and aggregate equivalence assertions. Timing is not expected to replay exactly. `run.log` contains original aggregate outputs.

## Design
64 independent procedural seeds split into primary 0–31 and replication 10000–10031, each run in independent and common-mode error regimes. 64 queries per seed-regime, 9 primary arms; 73,728 query evaluations. The three additional swap arms each have 8,192 evaluations. Each of 64 entities has 8 of 128 binary features. Four examples per entity with known identity labels and 25% feature corruption train additive synaptic counts; query corruption is 50%. The prototype uses dense NumPy operations rather than a true sparse kernel. Bounded top-four candidate resolution obtains at most two clean binary identity features from a simulated sensor. A surviving candidate can be wrong if the true entity is not in the shortlist or the two observations fail to distinguish it; this does not constitute a verified TAC implementation. The baseline shares the same active observation, verification, program learner and communications.

Four chronological write rounds, 12% probability of a wrong reading, with three observations per write. The shared-error regime adds 12% probability of a common-mode wrong record. Two-of-three exact agreement admits a write; otherwise retain the preceding value. Query asks for a 1/2/4/8-hop pointer-chain result followed by an unknown finite procedure. Ground truth always uses the latest actual world record, not the latest admission. Skill learning enumerates a finite library of observationally distinct compositions of three supplied primitives (length 1–3) and receives binary confirmation over all eight possible inputs; compiled execution is an 8-entry lookup per goal. Four instruction symbols and eight response symbols are independently permuted each seed and learned by trial feedback. This is a toy grounded communication protocol, not natural language; the task supplies the hop count and noisy cue separately rather than requiring learned parsing. All training is finite search/count updates, not neural optimization. No gold test path supplied to the execution logic; simulation sensor receives environment identity to produce one requested bit. The exact-cue ablation is intentionally weak with 50% corruption; nearest-exemplar swap is a stronger comparison.

Full-history reference computes softmax over all labeled association examples, aggregating by entity; exact memory retrieval scores every historical accepted event with oracle equality keys and a length-dependent recency logit, then decodes the weighted record values. This deliberately gives the reference exact keys and recent-write semantics. It is an engineered attention reader, not a trained Transformer or optimized attention kernel. Reader-only swap holds association and all other components fixed. Strict success requires correct decoded response, correct initial entity, each visited record matching ground truth, correct hop count and instruction goal. It does not imply the correct skill was inferred when another skill coincidentally returns the same output.

## Findings
Combined vs dense attention answer success: primary independent 86.77 vs 86.47%; fresh independent 89.70 vs 89.84%; primary common-mode 66.94 vs 67.14%; fresh common-mode 70.36 vs 70.46%. Combined strict success pooled independent 85.55%, shared 59.35%. Reader-only swap reproduced every per-seed aggregate; interpreted and compiled also matched every per-seed aggregate. The deterministic replay reproduced all 128 seed-regime aggregates. No proof of statistical equivalence, no preregistration, and the fresh seed panel samples the same generator. No true independent auditor.

Prepared CPU query timing (8 seed fixtures, 9 repetitions per mode, median of per-seed medians): see timings.json. Includes association, routing and simulated sensor computation, relational reads, procedure and reply; excludes learning, memory preparation/writes, actual observation acquisition, language tokenization, and physical I/O. Scaling benchmark measures only prepared exact record lookup vs a NumPy softmax scan, not full model inference, and compares a Python hash map with NumPy arrays; no hardware-optimized attention comparison. No claim of fixed total memory: exact state grows with number of live entities; dense synaptic table scales with entity count. Current candidate scoring scans all entities and is not bounded sublinear retrieval.

## Next gate
Replace synthetic module interfaces with original implementations from pinned CSM/TAC/LRC/BDH/Neuraxon research. Train a sequence model using identical raw byte/token streams and identical environmental interaction allowance, compare parameter/compute-matched full causal attention with no-attention hybrid, and evaluate held-out entities/relations/compositions/surface forms, later natural corpora. Separate fixed-history tasks (no extra observations for either model) from interactive tasks (both models get same observation budget). Measure semantic task completion, exact path, calibration/abstention, perplexity where applicable, time-to-learn skill, interference, training compute, end-to-end prefill/decode, memory, writes, physical observation cost, and throughput across context sizes. Add an indexed attention control, a recurrent baseline, and full factorial swaps. Do not qualify until genuine language task success and strong speed evidence at matched quality.
