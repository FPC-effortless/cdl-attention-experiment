# COG-ATTN-021–030 — Cognitive attention replacement, pilot cycle

## Scope and qualification
This cycle investigates ten mechanisms specified by the previous COG-ATTN-014–020 report. It uses standalone NumPy cognitive prototypes and small PyTorch causal models, not the original end-to-end TAC/CSM/LRC neural checkpoints. All environmental interactions and feedback are simulated. No natural-language corpus, general LLM, GPU, or public repository changes are included. This is NOT_QUALIFIED as a replacement for full LLM attention. The frozen protocol is `protocol.md`; `stress.py`, `integrated_stress.py`, `repair.py` and `causal_extension.py` are explicitly follow-up analyses, not prospective independent confirmations. No statistical significance or hardware-general speed claim is made.

## Methods and findings
- 021: Each of 64 worlds independently permutes six anonymous verbs over six given register operators (two directions of COPY, SWAP, modular ADD, two modular SUB directions). Candidate filtering sees only effects, not latent verb IDs. Complete observations identify 355/384 verbs on the first observation and all 384 by the third. The primitive space and argument structure are supplied.
- 022: Random single-coordinate observations retain the true hypothesis but identify 202/384 uniquely after eight opportunities. Choosing among eight candidate observation configurations by predictive entropy identifies 383/384. A follow-up uses independent 12% uniform replacement corruption (including accidental agreement), 12 observations, and the correctly supplied noise likelihood. Hard elimination yields 84/384 correct and 281/384 empty hypothesis sets; random soft posterior 288/384; active soft posterior 384/384. Candidate-bank construction is external and the model predicts effects of known primitive operations. No cross-sensor independence claim.
- 023: Position-independent count association recognizes 512/512 causal tokens amid random distractors; first-position counts recognize 509/512. One false distractor association was admitted in the clean count arm. In a follow-up perfect proxy co-occurs with each relevant token; unique-support filter abstains on all 512 until four rounds of proxy-removal interventions resolve all 512, with no false mapping. This is not unrestricted concept discovery; simulator exposes which register changed and supplies an intervention.
- 024: Four alias meanings are reassigned after 20 rounds and six revision rounds follow, each with three observations per alias, 10% uniform replacement probability. Frozen and cumulative maps retain 0/256 revised, 256/256 unchanged; supplied-version reset 256/256 both. Follow-up rolling 12-observation window (no version labels) reaches 256/256 changed and 256/256 unchanged after three rounds. It does not test neural continual learning or delayed conflicting revisions.
- 025: Active vs passive clean partial sensing: mean actual probes (early stop allowed) 13.859 vs 36.719 to acquire 99.74% vs 52.60% of meanings by eight opportunities per verb. Mean per-world selection-only CPU time about 0.841 vs 0.004 ms; candidate construction and environmental execution excluded. Acquisition cost modeled as count, not physical time. Selection is prediction entropy (equivalent to expected information gain under deterministic or symmetric fixed observation noise).
- 026/028: Four random eight-slot permutations inferred from unique-value state transitions. Compose depth 1/8/32/128, 128 states per seed/depth. All 32,768 evaluations exact. Truncate-after-eight baseline fails all 8,192 depth-32 and all 8,192 depth-128 cases. Prepared compiled results equal serial and evaluator. Follow-up benchmarks compare batch-vectorized iterative permutation against compile once and batch gather, 20 measurements per batch/seed. At depth 128, median separate serial/preparation/execution components (ns) approx 126182/24352/1432 at batch1, 155865/24249/1667 at batch8, 178826/24204/2123 at batch128. Sum of separate medians approximates total. CPU NumPy, only closure under permutation composition; general context-dependent plans not compiled.
- 027: Two output slots with independently permuted eight-symbol vocabularies. Learner receives single whole-utterance success bit, never per-slot feedback or gold tokens except inside simulator reward. Star-shaped training (15 pairs), 49 interior pairs withheld per seed. Flat pair table 0/3136 held-out, factorized 3136/3136. Feedback 30633 vs 6239. Slot grammar, action alphabet, meanings, and deterministic listener provided. This is compositional symbol production, not natural-language generation.
- 029: `causal.py` trains Transformer (18843 parameters) and GRU (20691) on the same 2048 sequences per seed, 8 writes and 2 read queries per sequence. Two learning rates, 320 updates each, batch 32, AdamW, full next-token cross entropy; select by validation retrieval then NLL. Initial test 256 sequences per seed/length, 8/32/64 writes, with queries every four writes. Full-forward CPU batch-one timings include all sequence positions, not cached decoding or quality-matched speedup. Oracle parser and zero baseline in `audit.py`: always-zero accuracy 49.80%, 22.82%, 14.73%, exactly GRU aggregate accuracy. Both are underqualified. Follow-up `causal_extension.py` continues selected weights on mixed 8/16/32-write histories, 768 updates/batch16, LR .001, selects checkpoint on separate validation. Test uses fresh seeds distinct from original. See JSON for all trials and counts. No test-informed hyperparameter choice within either fit family; extension motivated by initial weakness. Perplexity includes all tokens; retrieval measures only read values. The exact parser has engineered grammar and is not a resource-matched neural model or language-generation comparator.
- 030: Eight-command sessions, 64 per world, include learned verb mapping, learned referents and factorized learned speaker. Commands are shuffled tagged role/verb/filler tokens; argument role tags and initial observed state are supplied, no repeated observation at inference. Session succeeds only if every intermediate state and min/max register communication is correct. Complete 4047/4096; random partial 222/4096; no concept grounding 0; reset every command 0; oracle 4096/4096. Full primary 1999/2048; replication 2048/2048. Full intermediate states 32534/32768. Prepared Python CPU total 100.715 ms for 4096 complete sessions, excluding simulator generation, training, and environmental costs; not quality-matched LLM comparison. Follow-up uses independently noisy verb acquisition or two systematically biased verb channels with 12 observations per verb, posterior confidence gate >=.95. Active independent 4096/4096, random independent 471/4096; active biased 165/4096, random biased 37/4096. Active shared admits all 384 meanings but only 256 are correct; confidence is not truth. `integration_stress_results.json` ns field records acquisition time (overwrites the prepared-inference field from the helper); do not interpret as query latency. Shared bias fixture changes the perceived operator for 2/6 verbs and does not model general shared sensor errors.
- Repair follow-up: 12 initial biased observations, then separate independently noisy channel, up to 12 new observations. For 128 corrupted meanings, retain 0/128 correct, indiscriminate pooling 50/128, separately reset beliefs 128/128 at >=.95 posterior. All 256 unaffected meanings correct for all arms at end. Source trust/channel identity supplied, so this is not autonomous trust inference. Separate arm selects using new-channel beliefs only and replaces old beliefs; it does not infer the reliability of both sources.

## Reproduction
Python 3 with NumPy and PyTorch 2.10 CPU; single thread. From this directory:
```
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python studies.py
python stress.py
python integrated_stress.py
python repair.py
python causal.py
python causal_extension.py
python audit.py
python audit_extension.py
sha256sum -c SHA256SUMS
```
Run manifest verification before rerunning, as timings and checkpoint serialization can change byte hashes. Retained raw JSON is per-seed, with primary seeds 100–131 and replication seeds 300–331; neural seeds 11,29,47. `audit.log` and `audit_extension.log` preserve checkpoint and replay checks. Neural optimization itself has not been independently repeated, only saved checkpoint evaluation. See raw rows for exact denominators, timing components and selected checkpoints.

## Decision
Prioritize independently sourced evidence, source-conditioned beliefs and recovery; then learn actual semantic/grammatical factorization and primitive formation. Train stronger causal controls on varied lengths and require retrieval above simple frequency baselines as well as comparable perplexity before claiming quality-matched efficiency. Integrate the actual upstream modules, including sparse candidate routing and CSM/LRC compiled execution. Do not conflate this pilot's near-perfect finite symbolic execution with open-ended linguistic competence.
