# COG-ATTN-031–040 — bounded three-gate research cycle

## Decision
**NOT QUALIFIED as a full LLM attention replacement.** This cycle finds a bounded pathway to reliable operator induction, exact procedural execution, and competitive record retrieval. Gate 1 passes under its near-duplicate and orientation assumptions, but fails under less obvious correlation and global inversion. Gate 2 passes affine and fixed-slot structural diagnostics, not unrestricted discovery. Gate 3 partially passes: actual pinned source-file routines interoperate, the recency-biased learned attention control clears the retrieval criterion, and a follow-up symbolic integration achieves exact sessions; complete upstream trained-module integration and general natural-language communication remain untested. The standard full causal Transformer misses the qualification threshold at 32 and 64 writes. No repository was modified or published.

## Protocol and experimental accounting
See `protocol.md` for the prospective bounded design. Main procedural panel seeds 1000–1031 and disjoint replication 2000–2031; follow-up panels 4000–4031 and 5000–5031. The nine neural fits use three seeds (11, 29, 47) per architecture; 600 steps, batch 32, AdamW 0.003, curriculum on 8/16 and later 8/16/32/64 writes, validation selected from steps 200/400/600. Held-out benchmark uses uniform values, queried keys have appeared, and structured key/value record tokens rather than raw text. All numerical observations are synthetic except BANKING77 utterances. Simulator feedback for the latter is also artificial. Timings are single-thread CPU measurements; not accelerator or deployment benchmarks. No claim about broad external scientific novelty is made.

## Gate 1: source reliability and epistemic defense (031, 032)
Seven binary evidence channels, 512 unlabeled calibration samples and 512 held-out observations per seed and condition. Shared regime: independent good sources flip with probabilities .04/.09/.12; a latent inverted channel flips with probability .92, then four copies independently flip with probability .01. Estimate clusters by >.95 raw agreement, collapse each cluster to its vote, estimate latent truth and per-group sensitivity/specificity using EM. The latent label is oriented by the prior that average group competence exceeds chance. No trusted source label used. Independent condition: seven channels at .04/.09/.12/.14/.17/.19/.22 errors. All-inverted complements the shared regime observations, with the same latent truth. Majority and learned are evaluated on identical cases.

| Regime | N | Majority correct | Learned correct | Admitted (confidence >=.95) | Admitted correct |
|---|---:|---:|---:|---:|---:|
| independent |32768|32530|32550|31871|31832|
| shared |32768|3478|32364|31526|31470|
| globally inverted |32768|29188|414|31511|59|

Shared admission precision 99.82%, coverage 96.21%; unanchored truth accuracy 98.77%. Grouping identifies exactly four groups in all shared main seeds. Inversion exposes label switching, not a resolvable observational problem without an orientation prior or anchor. Follow-up uses 1/3/5 separately supplied known outcomes to orient the posterior, not autonomously discovering known truth. At 3 anchors: shared 32395/32768, all-inverted 32375/32768. At 1 anchor the shared result drops to 31387/32768. Weak-duplicate stress (copy error .10) fails: threshold detects seven groups in all seeds; learned accuracy 2017/32768 (6.16%), majority 10993/32768. This is a serious limitation of raw-agreement grouping; it is NOT general causal discovery or arbitrary residual-dependence detection. The appropriate next gate is latent common-cause inference with interventions, calibrated uncertainty and abstention if orientation is unresolved.

## Gate 2: operators, structure, conceptual transfer (033–037)
033: exact modular linear system solver over F_11 learns an arbitrary affine map of three variables from eight I/O pairs. 512 unseen affine maps; all admitted, 65536/65536 held-out executions correct. Nonlinear challenge adds x0*x1 to one output coordinate, outside affine class: all 512 rejected, zero executions counted correct. No operator enumeration, but an affine inductive bias, known domain, known dimensionality and complete I/O observations are provided. Matrix orientation in code uses row vectors `[x,1] @ A`.
034: randomized three-slot role assignments are inferred over six permutations using 24 state transition examples; tokens drawn from same lexicon; held-out combinations defined by sum mod 4. Clean 8192/8192 correct across 64 environments. The initial 'ambiguous' arm removes one semantic term but is still identifiable by exclusion, also 8192/8192. Follow-up deliberately makes two roles symmetric: exactly 2 surviving assignments per environment at 24 observations; asymmetrically weighted operation observations (known functional form) distinguish them; unique role assignment in all 64 at 48 observations. This is fixed arity/known operational semantics, not grammar induction from raw natural language.
035: supplied two-factor additive structure, 8x8 possible concept combinations; star training identifies 15 combinations and predicts all 3136 held-out pairs across 64 worlds; abstaining whole-pair lookup gets zero. This does not discover factor count, hierarchy or independent semantics.
036: official BANKING77 splits from PolyAI task-specific-datasets repository, CC BY 4.0. Train=10003, test=3080, 77 intents. Pin Git blobs 98e2543cf482d0dca7bfb175ebe35d98efad95be and 799687a8367359432985b8b13d85a2baf73f92dd. Run in GitHub connector runtime on fetched corpus; saved aggregate results and independent local reproduction script; corpus not included and local script not replayed with corpus. Shared categorical feedback: 3 good sources error .10/.12/.15, 4 shifted-label near-duplicates .01 copy noise. Raw agreement clusters on separate simulated 512 labels, grouped majority abstains on ties. Sparse word/bigram TF-IDF-style action profiles learned on admitted labels only. Gold feedback 7623/9240, raw majority 43/9240, grouped 7630/9240. Same test set repeated under three feedback seeds, not 9240 distinct utterances. Correct grouped training labels 28652/28700 admitted. No actual action execution or grounded speech production; this is authentic input intent routing only. `banking036.mjs` reproduces with pinned CSVs; requires Node. No claim of general authentic task integration.
037: compose 64 arbitrary deterministic finite-state transitions on 256 states, table compile; 512 test states/seed, 32768/32768 exact. Aggregate serial 7.482 ms; prep 5.794 ms + prepared lookup .0756 ms. Table 2048 bytes/seed (int64 payload). Cost includes table compilation but not rule generation; this finite-state method can require exponential state space. Follow-up composes affine matrices over 12-dimensional state (13 homogeneous coordinates) and checks against CSM sequential writes; structure is known, not universal compilation.

## Additional cost-aware curiosity follow-up
Independent binary sensors: cheap error .25/cost 1, expensive error .05/cost 4. Stop posterior >=.95 or 24 observations. 16,384 trials per policy, matched latent truth; cost-aware I-.12*C vs I-only both always select expensive. Cheap: 15781 correct, 92300 probes, cost 92300, 38 below posterior threshold. Expensive, I-only and cost-aware each 15545 correct, 16384 probes and cost 65536. Total selection-only CPU ~5.52ms cheap, ~1.30ms expensive fixed, ~255ms information and ~256ms cost-aware. No added value from information scoring or the particular cost regularizer in this sensor regime. Cost/accuracy tradeoff exists but not evidence of a successful learned adaptive policy. This is additional exploratory evidence, not preregistered. Single-step greedy reward does not model downstream cost; next cycle should include heterogeneous acquisition costs and control amortization.
