# COG-ATTN-014–020 — consequence grounding, curiosity and persistent cognition

Local CPU exploratory research cycle, November 20, 2026. All seven directions have executed bounded diagnostics, **not** an LLM qualification. `protocol.md` was written before the first runs, not independently timestamped or externally registered. Three neural seeds (11,29,47), 16 training graph seeds (100–115), 16 primary evaluation worlds (500–515), 16 disjoint follow-up worlds (600–615). World results are pooled over episodes, not independent observations of neural fits; no significance test. Follow-up vectorization and persistent rollouts are exploratory. Existing upstream TAC, CSM, LRC models are not loaded in this cycle: alias tables, indexed state arrays and graph transitions are simplified analogues. No real-world interaction or open-ended language decoding. No GitHub publication.

## 014: novel entity alias acquisition
16 worlds x 16 random alias-to-entity permutations. Binary feedback on candidate referents, 2.5% independent bit flips, supplied set of 16 candidate entities. Frozen identity mapping has 15/256 correct, single noisy feedback 207/256 (1957 feedback calls), majority of three 253/256 (6471 calls), clean majority 256/256 (6528 calls). Feedback is generated by simulator, no supplied mapping in the learner. Probing fixed index order and stopping at first positive are engineered; no realistic word segmentation, absent referents, correlated noise or learning unfamiliar verb meaning. Costs are feedback counts, not physical observations or latency.

## 015 and 019: outcome training / attention controls
24 total fits = 3 seeds x 2 architecture families x 2 objectives x 2 learning rates. CNN 6265 parameters, single-layer full bidirectional message-attention encoder 6665 parameters, top-8 of 24 feature activations for both; same initial seed within a family; 1600 generated training instances; 180 AdamW updates per fit, batches of 64, lr .001 or .003. Model selection on 512 validation examples, six familiar templates plus one additional template; evaluate at 60,120,180 steps; max validation accuracy then earliest checkpoint, first LR on tie. Equal update budgets, not equal FLOPs. Validation uses evaluator direction labels, which audit verifies are exactly recoverable from observed state deltas; outcome training itself never uses explicit direction labels. Each of five held cohorts contains 1024 examples per seed, disjoint RNG from training. Pair split `(a+b)%5==0` vs otherwise; syntax templates explicitly disjoint. Candidate entity positions, IDs, quantity, transfer operator supplied. Two directional interpretations generate candidate state deltas; observed before/after makes exactly one valid. Thus NLL of valid interpretations is algebraically equivalent to ordinary direction CE. Not an ambiguous latent-language task, no role-label-free open discovery. Unknown non-entity words collapsed to UNK. No causal LLM or full-context baseline; matched message-level encoders with same exact execution. Novel verbs remain near binary chance. All results are exact direction classification, not whole-message tags or full state accuracy.

## 016: curiosity and transition acquisition
Simulator exposes resettable state IDs and four actions. 8x8 directed grid worlds with randomly omitted edges, permuted action IDs. Each policy has 128 probes per world; total possible state/action pairs 256. Random with replacement, exploit by highest smoothed success, curiosity least-count. Observed valid transitions used to plan new goals. 1014 of 1024 random goals reachable on true graph; only these scored. Coverage total unique probes across worlds: 1585 random, 19 exploit, 2048 curiosity; valid learned edges 1137, 16, 1476 respectively. Goals solved 63/1014, 0/1014, 195/1014. All paths checked in true environment. Curiosity avoids familiar-action trap but coverage remains inadequate; choice among resettable states is a strong simulator affordance.

## 017: learned planning
L1-regularized linear heuristic, 10 engineered geometric/degree features, 9 nonzero coefficients, 8018 reachable training state-goal pairs from disjoint worlds. Training uses exact shortest-path distances derived from observed graphs; not outcome-only neural heuristic. Primary graph query uses fully observed graph. Coordinates supplied to both Manhattan and learned heuristic. BFS is implemented as heap search with zero heuristic, not optimized deque. Budget charges transition references, not scores or CPU time. All successful paths verified, path lengths compared against exact BFS. Heuristic not mathematically guaranteed admissible. 1014 reachable goals.

## 018: incremental associations
64 landmark/world combinations, 32 edge insertions each, 2048 incremental snapshots compared to complete shortest-distance recomputation. Exactly equal every time. For an inserted edge u->v, propagate distance decreases from v if d[u]+1<d[v]. No support for efficient arbitrary deletions, 64 deletion cases fall back to full rebuild and check exact equality. Aggregate checks 10252 incremental vs 487032 rebuild (47.51x fewer); time 4.19 ms vs 190.01 ms (45.34x), plus initial prep 5.81 ms (incremental + prep 10.00 ms, 19.01x vs rebuild excluding its initial prep); deletion costs excluded. Python CPU loop microbenchmark, not end-to-end model speed. Full rebuild uses exact queue BFS; incremental cache memory O(landmarks * nodes).

## 020: integrated workflow
16 primary worlds, each with 16 random aliases, 4x4 directed grid with all 64 state-action pairs probed (including invalid), 128 generated unfamiliar-syntax requests per world with held entity pairs; three neural training seeds reuse each world. Binary alias feedback independent 2.5% errors; initial balance observations independent 10% ±1 errors per record per reading; verified uses median of three readings. Exact executor applies transfer only after plan found on learned action graph; verifies every primary successful path against true world. No output language generation, no continual neural weight updates. Grounding name slots and quantities supplied, path semantics fixed, state arrays simplified not upstream verified CSM. Primary accuracy denominator 5694 reachable requests x neural-seed replicates; unreachable true requests excluded consistently. Full 4343/5694 exact, attention 1896, frozen mapping 0, no verification 1056, unguided 4343, oracle direction only 4347. Full ground identification 5604, correct route 5599, direction 5689; direction-only oracle retains alias/noisy state, not full oracle. Full planning checks 87992 vs unguided 183312; time 500.60 vs 82.53 ms (includes heuristic computation, not neural forward, construction or environmental observations). No end-to-end inference speed comparison.

Disjoint follow-up (600–615): 64 four-command sessions per world, 2682 eligible session-seed evaluations after excluding sessions with any truly unreachable request. Three neural seeds share environments. Starting balances 50–99; no new sensor readings during session; each parsed transfer changes current memory, executable path necessary; exact full-state comparison after every command. Reset resets each step to initial noisy verified state. Full oracle bypasses grounding, sensing, parsing and planning. Full 7910/10728 exact steps, 1917/2682 exact final states, 1914/2682 complete sessions (all four steps exact); attention 246 complete; no verify 419; reset 0; direction-only oracle 1935; full oracle 2682. Four-step integration remains bounded and quality below oracle, no deployed system. Follow-up is a fresh procedural world panel, not independent training replication.
