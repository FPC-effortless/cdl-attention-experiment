# ROLE-NAME-REMAP-001: prospective held-combination identity probe

Purpose: test whether the earlier second-clause failure recurs by literal
identity under controlled substitutions. The four "fragile" strings
(gio, jay, kai, ola) were selected on an earlier exposed panel; they are
not a prior distribution of names or labels of people. This follow-up
tests recurrence on fresh combinations of familiar one-token names and
one grammar. It does not test name-independent language or a new fit.

## Controlled actor

24 paired blocks (RNG20261128), each with an identical distractor and
two colors and four focal-name variants: two fragile and two controls.
Each variant has the full assignment × rendered focal-clause position ×
queried-entity crossing. Hold values, statement order, queried role and
answer fixed within each substitution. A focal-query substitution
changes exactly two visible name tokens (its clause token and final
query); a distractor-query substitution changes exactly one (focal clause
token), leaving the actual queried name unchanged. Within-class swaps
use the identical substitution dose on the same cells. Distractor
prompts check propagation to the untouched binding, not equivalence of
one- and two-token shifts.

All six unordered fragile pairs appear four times; structurally matched
control pairs follow the same schedule. Four controls (di,pam,eli,lou
matched respectively) were chosen deterministically from the other 12
names without errors in the prior late second-query diagnostic, by
minimum total absolute TRAIN family-exposure difference; lexicographic
tie break. Focal names each occur in 12 blocks. Each of eight remaining
distractors occurs in three. Each block's two colors are common to all
four variants. All 96 joint name-pair/color-pair families exclude the
832 exact prior keys. Randomize actor row order independently from
unstaged judge-only grouping/answer metadata. No old/protected TEST,
MAIN, additional fits, paid compute or publication.

difference from averages across both focal names per class and both
assignments, and paired 95% percentile interval by resampling 24 blocks
(2,000 samples, Python Random(20261128)). Evidence of common recurrence
only if positive interval lower bounds for both registered models; one

frozen names and recurring distractors limit independence and inference
beyond these registered blocks. A cross-class difference is a result of
these literal substitutions, not proof of a mechanism or a deployable
repair.
