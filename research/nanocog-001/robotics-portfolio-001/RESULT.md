# ROBOTICS-PORTFOLIO-001: First civilian forecasting and simulator results

**No architecture won across the task portfolio.** In an eight-family civilian test suite, three families have an exploratory learned comparison and five have engineered reference replays only. The most informative learned result is TAC-OSM's tolerance of synthetic ventilation sensor drift. COG span exchange had a smaller advantage over tied attention on noisy and missing displacement readings; simple sensor rules remained competitive or better. None of this establishes real robot competence.

## Offline forecast results

Matched observed histories of length 24, 1,024 nominal FIT episodes per task, four 256-case held panels, three paired seeds, and 192 AdamW × 32 exposures per fit. Held nominal/noisy/dropout/transition panels repeat the same underlying held families, not independent scenarios across panels. No test-time tuning. Tied native COG, Stage 1m span ×1/×4, and exact TAC observe-only equations are continuous-input adaptations trained from scratch. They use comparable, not identical, capacity: 10,171–11,301 allocated parameters. Native TAC action/feedback, full PULSE and the eventual complete closed-loop system are not part of these fits. Neural controls: last-step MLP, GRU and tied SDPA. Same training examples and optimizer schedule do not imply equal FLOPs.

All table values are means across three seeds where applicable. MAE is in fabricated distance units; anomaly uses macro recall, higher is better.

TAC's transition gain over the fixed engineered control was 10.90 points (descriptive paired family/seed bootstrap interval +6.89 to +15.33). The same engineered method outscored TAC on dropout. TAC's batch-one history-forward median was approximately 3.62 ms versus 0.24 ms for tied SDPA on the anomaly fixture; these are warm model-only timings on one CPU, not quality-matched serving measurements. For noisy odometry, COG ×4 decreased MAE versus tied SDPA by 0.68 (paired interval 0.28 to 1.02 lower), but even command-only scored 2.34 under that stress; the control is the same algorithm in every panel, not a learned regime selector. For held occlusion reversal, the recent-motion and all-history baselines have very different failure patterns, so superiority to just one of them does not demonstrate robust prediction. Almost all nominal anomaly variants hit ceiling early; nominal performance alone is not a useful discriminator.

## Other five families: executed references, not trained models

- Fixed-station ground-cart docking, dimensionless tank regulation and symbolic spill containment: script succeeded safely in 288/288 reference episodes; idle completed 0/288. The protocols covered 48 scenario seeds, two regimes, three tasks and two rules, for 576 episodes and 13,824 transitions. Replays were byte-identical. This comparison against idle validates task construction, not policy quality.
- Warehouse reassignment: 32 paired scenarios, 40 ticks; centralized current-state exact reference completed 110.47 jobs per episode vs 92.44 home-only and 91.00 lagged local.
- Workshop queue admission: 32 paired scenarios, 40 ticks; centralized exact reference 53.13 completions vs 50.13 lagged and 49.31 static. Admitted work used the same spacing validator. Centralized references have an information advantage. These are engineered workload checks, not learned benefits or physical motion results.

No model controlled physical hardware. No target-pursuit, interception, capture, or tactical flight trial.

## Audit and next admissions

Initial isolated worker did not reach a model because a runtime environment variable was missing; the restored environment used the same data, code and fit budgets. Its worker exited normally after all **63 fits** and sealed 64 tapes/observation artifacts. **TrainLab marked the run failed**: the producer returned numeric observations without the required recipe/input-bound receipt structure. The untouched failed record is retained. A separate custody check verified every declared artifact identity and metric shape; a second endpoint calculation matched all 252 model/seed/panel results. Scores above are exploratory retained-output evidence, not a TrainLab qualification. No scientific rerun.
