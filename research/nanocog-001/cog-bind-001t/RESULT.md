# COG-BIND-001T: modifier placement breaks the old reader; event-first normalization does not repair copying

## Findings
**Modifier placement was the strongest consistent break in the frozen reader.** Moving the exact same four-word phrase from the end of a fixed passive event to between its item and predicate reduced accuracy on questions about that event from **8,030/12,288 to 1,172/12,288** across the six original 001S fits. All six declined (23.73–82.13 percentage points). Companion voice effects were smaller and inconsistent; the extracted event remained a passive throughout this contrast. Prefix/suffix question variants had identical decoded answers in all 24,576 matched comparisons. That is expected for this particular model: its question representation pools without positions, and the variants have identical tokens. It is not evidence of general question-syntax transfer. The frozen familiar calibration varied from 547 to 948 of 1,024 because this is a fresh population and not the original 001S test.

**The event-first reader found the right event more often, but copied its item less reliably.** In all three fresh, matched seeds, it chose the right event more often than the direct pointer, but answered fewer exact swap and changed-question pairs. No event-first seed qualified. This is a stronger diagnosis than just noting end-to-end failure: even forcing the correct event on the saved token scores did not close the gap.

The shared architecture change did help the hardest slice: on modified-passive targets with the modifier in the middle, exact answers rose from **1,724 to 2,818 of 6,144** pooled model-row observations, improving in all three seeds. On the corresponding trailing-modifier cases, exact answers fell from **5,348 to 2,628 of 6,144**. The apparent gain in the hardest slice does not qualify the repair: it lost much more on the easier paired conditions.

Selecting each fitted model's own global MAP or using its own implied event marginal for hard decoding changed at most two swap pairs per seed. The copying failure is therefore not explained by hard-versus-soft decoding alone. A post-seal intervention that forces the *other* event, keeping the question and raw scores fixed, also shows inconsistent copying of that other event's item (direct 4,918/3,812/6,970; event-first 5,588/2,664/5,688 of 8,192 per seed). This measures conditional copying, not correctness on the original question, and does not prove learned causal mediation. The nearest unique lexical cue got 3,456/4,096 novel swap pairs and 2,816/4,096 question pairs. An exact engineered grammar reference solved the constructed test. Strength here is diagnostic isolation, not superiority to that grammar or general natural-language competence.

## What was tested
001S could almost always extract the active event's item but rarely the passive event's item with a modifier inside it. These factors were entangled. The diagnostic here crosses the voice of the *other* event, the placement of the same modifier in the fixed passive event, and the placement of the same question time marker. It compares the same assignment, question meaning, items and displayed event order across conditions. Moving the modifier keeps the exact clause word bag, moving the question marker keeps the exact question word bag, and changing the companion voice changes the relevant auxiliaries, order and length. The factorial concerns these particular constructions, not a general claim about all passive language or modifier semantics.

Train/dev/held include 256/64/128 distinct semantic families. Every family has 8 rows crossing both item assignments, both questions and both display orders. The same 128 held families appear in eight factorial cells with 1,024 rows each; they are not eight independent test sets. The held familiar calibration is the same families with homogeneous voices and no clause modifier. New names and item spellings were not present in the original 001S examples; character spellings use an existing character vocabulary and the exact same prior trainable parameters. The frozen model receives both raw texts but no event boundary features.

The fresh comparison uses a 14,128-parameter backbone with identical per-seed initial weights, data, outcome-only objective target, update count and observed examples. Both arms get the same observable comma-and split, derived from input text; no gold event identity, item role tags or candidate list is passed in. Direct normalizes the event and token scores globally. Event-first normalizes event choice and conditional token copying separately, then chooses the event before the token. The comparison tests that combination, not a difference isolated to one mathematical operation. Recomputing both decoders on the saved distributions helps separate those effects. The architecture uses local convolutions and bounded clause/query soft matching, not a qualified attention-free language model.

## Decision and reproducibility
Do not promote the conditional event-first normalization as a repair. The next test to prioritize, if pursuing this bottleneck, is transfer of within-event item-role extraction while holding event selection fixed, followed by an end-to-end check. In particular, compare a query-independent event-object copy path against the existing query-conditioned token scorer on fresh, separately held wording. Do not reuse these exposed examples to qualify a repair.

Six frozen readers replayed on 60 truth-free panels and six fresh CPU fits used 384 updates each; 60 new blind prediction panels were sealed. Independent decoding and recount reconciled the stored predictions. The initial fresh scorer stopped at a numerical check: the NumPy float32 reference violated its comparison tolerance for 37 scalars. Scorer-only arithmetic promotion to float64 passed the same tolerance without changing weights, predictions, policy or scientific thresholds; the original run and code were retained. No reruns of training or prediction.
