# COG-COMM-001: qualification protocol for bounded communication

**Status:** Public design summary (not the operative sealed admission protocol). Prospective qualification only. The data-only materializer receives independent exact-byte admission; this document itself never admits fit or model results. Training/comparison numbers remain proposals until the separate exact fit/evaluation freeze. CONSTRUCTED, local development diagnostic, NOT_QUALIFIED. “Memory-free” means no writable semantic record store, persistent identity table, cross-episode retrieval, or replay from hidden gold. B retains completed-prefix aggregate statistics and C additionally retains bounded per-token scratch **within** an episode; account for the bytes and lifetimes. No protected TEST or paid compute. Publication is limited to safe aggregate and engineering source.

## Question, controls, and attribution

Can a causal local decoder use bounded summaries to answer a token about information outside its real local receptive field? Does the incremental routing configuration improve over the summary-only one, and does query-dependent subscription improve over an otherwise identical scratch architecture with content-blind receiving? Use the same pinned attention-free nanoCOG decoder shell: width 32 and two layers initially, same tokenizer, embeddings, local field, MLP, residual/norm, losses, and candidate no self-attention or borrowed SSM. Report common tensor initialization parity by seed, active trainable and total parameters and head/module differences. Target <=5% active parameter difference, where practical; inactive placeholders do not count. If budget, information, capacity, routing estimator or computation differ, report actual differences; this matrix is an incremental implementation comparison, not proof of routing alone.

| Arm | Same actor history and token loss | Distinguishing online path |
|---|---|---|
| A | Identical ordinary causal input and chunk schedule | Local finite field only; no closed-chunk packets or hidden accumulated recurrent state. |
| B | Same history and loss, no retrieval indices | Learned fixed-width moment summary of all completed blocks; fixed stored bytes but cumulative age, not a discrete per-chunk bank or FIFO selector. Keep open-block moments inaccessible until close. |
| C | Same history and loss, no retrieval indices | B plus a separate query-dependent per-token scratch path (not selection among B packets). Read strictly earlier writes, even in the same block. Topic capacity and age limit both apply; age eligibility does not prove storage survival. |
| C-blind | Same history and loss, no retrieval indices | Same C architecture/total parameters, fixed round-robin content-blind topic pair and uniform subscription weights. Publisher, admission, payload and downstream path still learn. Subscriber parameters receive no gradient in this arm, so active counts differ. |
| D | Deferred | Only after initial evidence and separate preregistration. Compare fixed C against C+learned binding at the same causal loss and target masks, without ID/address/operation supervision or new oracle access. |

B versus C is a nested system comparison, not routing isolation. C versus C-blind measures the specific learned subscription package versus fixed receiving under matched architecture, while publisher/admission may adapt differently; it does not isolate routing scores under identical acquired data. Same-checkpoint fixed substitution, if prospectively frozen as a separate intervention, can isolate receiver-rule effects conditional on endogenous data and path; it is not a trained baseline. If claiming benefit over competent fixed addressing, add a strongest admissible same-information, same-width receipt/retention baseline before outcomes (e.g. deterministic recent topics with matched activated reads), or explicitly bound the claim to this one fixed schedule. Include a fixed no-message/disabled-summary control and a strong deterministic actor-visible parser/expected-answer sentinel (not an allowed model input and not a learned comparator). If the parser cheaply solves the task, a positive C result still only tests the learned mechanism. A learned longer local/recurrent reference, if added, must be marked unmatched unless it genuinely shares capacity and information. Never change baselines after outcomes.

## Actor-visible corpus and data gate

- Render normal token streams with multiple prior evidence chunks (independent alias/value assignments and distractors) and a current query naming a *visible* alias. Use a shared frozen train-only tokenizer; distinct held aliases must tokenize injectively into multiple legitimate pieces, not merge to identical UNK. Retain exact tokens, roundtrip/prefix audit and prove the answer is one fixed vocabulary token if claiming next-token exact (otherwise preregister exact continuation across all tokens). No new tokenizer fit on CAL/DEV.
- Whole family precedes split and expansion. Two opposing outcomes per family: identical query, exact entire local receptive suffix, length/layout/distractors/target offset and relevant full input token marginals; change earlier correct value by exchanging assignments. Balanced orientations; independent RNGs for alias↔value, placement, distractors and orientation; repeat by label, age, position, and actor-visible role. Show neither absolute geometry nor recency selects the right answer systematically. Eligible pairs must be distinguishable within the full permitted causal view and have reachable earlier source in the declared retention budget. A no-fit independent interpreter must recover the correct result on every eligible case from *only actor-visible history*, independently adjudicating authority, chronology, source closure and reachability, not trusting an actor-hidden slot flag. Retain but classify eviction, absence/future-only, collision and near/local groups separately. Only use absent/future-only as accuracy if there is a frozen abstain target/sentinel in every arm; otherwise evaluate invariance to changes after a cutoff.
- No model-facing row/world/seed/orientation label, answer, truth, provenance-derived ID, query→slot mapping, source hint, answer-bearing event feature, precomputed routing decision or oracle packet. Ordinary aliases repeated in both evidence and query are fine; generic structural masks/chunk boundaries must be fixed independently of label or causally derived from identical visible inputs. The sender builds fixed-width packets only from already-seen chunks before the query arrives. No hidden full-context encoder or roster lookup. Target CE applied only after the model emits logits, never as a model input. Inputs besides tokens, ordinary masks and constant geometry are deny-by-default.
- Separate TRAIN/CAL/DEV by complete family; no protected TEST. Current fixed grammar supplies a held **lexical** DEV with unseen aliases, not structural transfer. Freeze this as the named primary unless genuinely distinct topology is independently demonstrated before outcomes; an optional separately frozen interpolation panel is supportive only. The DATA roster is 320 TRAIN, 120 separately designated CAL, 240 held lexical DEV families (two opposing worlds per family), operator-held generator seeds, with delays 0, 2, 4, 8. Minima by delay are 80/28/60 families and minima by answer are 80/30/60 worlds (TRAIN/CAL/DEV respectively). CAL cannot be used for geometry or model tuning; its purpose, if any, must freeze separately. All 240 DEV families must pass the joint local-suffix-equality, nonlocal source, and scratch age eligibility rule. If actual roster fails, stop without seed hunts, clipping or downselecting. Report actual class support and prior cells by causal role, age/source position, orientation, eligibility and target. Detect exact/reverse-pair token duplicates, split crossing, semantic/rekey near duplicates within held motifs, chronology/permission overlap, and selected-vs-unfiltered dataset differences. No salt-hunting. Sidecar strata/truth private and scorer-only. Blind predictor closure gets only sealed checkpoint plus actor tensors/text/masks, not TRAIN or truth; separately hash the truth and exact actor IDs and require complete prediction ID closure before verification.

## Pre-fit blockers: leakage, causal semantics, training signal

1. Derive and independently test the actual receptive field (layer composition, embedding smear, local convolution and carry). Every nonlocal truth-changing perturbation must precede it with positive slack. A deterministic A on identical actor-local views with different gold values can have no both-correct pair and at most one single-row success per pair; any violation blocks. Test future suffix, query after cutoff, other batch neighbor and order, padding, reset/new document, already consumed state, stream versus batch including boundaries. Batch/stream parity must hold within predeclared tolerance; B’s block summary cannot be read before the source block closes; C scratch can read earlier tokens of the current block but cannot read current/future/padded writes. Read/write timestamps and eligibility must come from causal processing, not from a target-bearing builder sidecar. Include mutated negative controls and no carry across alternatives.
2. Record independent query-only, bag-of-words, relative-position/length/alias-frequency/label support and counterbalance audits, plus unseen-alias rekey. Failed balance, tokenization aliases collapsed, candidate reachability unsupported, unmatched paired local views, or baseline leakage are HOLD even if later scores look good. Independently reconstruct target timing and confirm no teacher-forcing breach: no occurrence of its answer position in the prefix used to predict that answer. Do not withhold legitimate small common context or remove any group after seeing model outcomes.
3. Verify B/C chronology and payloads for every metadata cell: no use of future query to build sender summaries, exactly declared cap and freshness/eviction, real transmitted/stored coordinates, no placeholder actor claims. Distinguish age-eligible source, literal source event span published, retained and read. A literal position miss is not proof of lost information because later payloads and higher layers can carry earlier conditioned information. Never subset the main denominator after seeing those traces. Check paired nuisances (equivalent packet rekey/permutation only when metadata semantics preserved, wrong-source or randomized matched sham, blocked packets and post-close order). Require training signal to sender and C’s learned route under the **same frozen shared prediction objective**. A detached argmax + gather alone is not trainable by CE. If using a soft mix within bounded admission or an explicit STE, document exact forward/backward difference and time spent scoring/mixing candidates; do not call a dense training mix a sparse inference savings result. Guard finite nonzero route/head grad on a constructed fixture where multiple packets are eligible; irrelevant or masked paths require expected negative gradient behavior. Presence of gradient proves wiring, not learned routing.
4. Trace or value leakage test changes hidden truth, family IDs and evaluator metadata without changing blind actor bytes/model inputs. Hold until exact source, recipe, runtime, split and source/evidence closure are reviewed. Record any geometry or capability fallback, but never treat a failed run, saturated cap or inserted label as a pass. No model work during independent source/admission review.

## Common training and frozen evaluation

Same vocabulary, examples/schedule, target masks, supervision, optimizer and committed updates across every arm and seed. Current integrated code combines common next-token LM CE, answer-token CE and a pair-supervised foil margin softplus. This is not ordinary LM-only CE and uses the other world’s gold as a foil at loss time. Freeze composition/coefficients and target masks/denominators equal across all arms, and prove neither answer nor paired targets are actor forward inputs. Report the coefficients and uncoupled/individual outcome metrics. Do not count the same final answer accidentally twice by also including that target in the ordinary prefix LM denominator. If a later LM-only arm is desired, that is a new matched experiment. Same shared seed tensors where compatible; freeze RNG ownership/init, serialized batches, AdamW/LR/warmup, clipping, CPU threads/dtype, and final-only checkpoint. No selection by CAL or DEV unless a CAL decision was fixed before spend; no favorable seed or checkpoint cherry-pick. Report actual parameter count, committed updates, token and supervised target counts, skipped steps and packet bytes independently.

**Primary:** both answers correct in both worlds of an eligible held-lexical DEV pair; ordinary full-vocabulary greedy (lowest ID for exact ties). Per-seed repair/damage counts and denominator by named stratum, and family-blocked paired interval that resamples families once, with both worlds and all seeds attached. Multiple seeds/paired rows are not independent families. **Secondary:** single accuracy, unweighted per-target CE (separate answer and ordinary prefix), correct-vs-paired-foil margin, reachable vs selected vs decoded source, incorrect commits on no-support, near/local competence and all categorical/finite parity. External route references and truth are evaluator-only, except clearly separate privileged oracle comparator diagnostic using the same authentic packet content; never count it as model inference or place answer-bearing values in state.

Suggested prospective pass policy (freeze with lead before run): A zero nonlocal both-correct pairs; on held-lexical eligible DEV, B and C each improve by >=10 percentage points over A with family-blocked CI lower >0. C vs B and strongest admissible same-budget fixed comparison improve by >=5 points with CI lower >0, no seed loses >5 pp and >=2/3 seeds favorable. Without a stronger fixed same-info control, C may pass the bounded tested-control comparison only; no general routing-superiority claim. Effects must not come solely from generic packet nuisance: require content-targeted packet disable/wrong-source to remove some rescues relative to competent matched neutral/irrelevant sham, and preservation under identical/causally equivalent packet/no-op; freeze actual denominator and positive-control logic before seeing outcomes. Specify acceptable matched damage thresholds to near/local and no-support cases first (suggest <=0.05 nats/token common local CE loss and <=5 pp extra no-support errors). If criterion or false-negative control is unsupported, explicitly retain BLOCKED/INADEQUATE rather than quietly converting that dimension to narrative.

## Budget, resources, timing

Minimal proposed plan: width 32, two layers, actual B aggregate geometry and C two-topic-of-four reads, max two entries per topic, age horizon 64 aligned blocks ×8 tokens subject to overwrite. Eligibility is source-token and query block difference <64, not survival over 512 tokens. Fixed packet resident cap remains eight payloads (two per topic) and there is no change to the local model’s eight-token inclusive causal field. Prior inert fixture found 16/80 age-eligible worlds under 16 blocks and 80/80 under 64 blocks; this is geometry, not retention or performance. DATA may audit up to its explicit 1,024-token no-clip ceiling; the current 512-token maximum is a forecast for fitter geometry, not permission to silently truncate or assume actual lengths. A/B/C/C-blind ×3 fresh seeds, provisional 128 fixed committed updates each, minibatch eight paired-balanced episodes. Before selecting a cap, audit real encoded length percentiles/range and retention relative to the actual held aliases/ages; do not silently truncate or assume T128. If every episode fits 512 tokens, <=524,288 positions per fit and <=6,291,456 across twelve before subtracting pads. Use real measured padded and nonpadding lengths and separately count supervised positions; log real nonpad target count and distinguishing active work. One-thread CPU only with separate DATA, FIT, PREDICT and VERIFY caps. No fit cap admitted. Inert T448 timings about 0.81 s C and 0.61 s C-blind per eight-world step imply roughly 104 s and 78 s of step-body time per 128 updates, before process/serialization/padding/counters. Re-measure at actual frozen shapes and justify fixed per-arm/aggregate caps with margin before fits; do not reuse the earlier 75 s/fit estimate. Consider frozen balanced length buckets over the exact roster to avoid padding waste. If cap cannot clear with margin, narrow prospectively or HOLD, never increase after cap to chase outcomes. One attempt per run, stop and retain all failures; no hidden retries. The DATA dossier only observes geometry, never calibrated learnability or survival. It always places a common proposal, closing sentence and query after the changed writes; a nominal zero delay is not automatically local. Prespecify a distinct actor-visible easy/local positive with explicit coverage and held outcome criterion (suggest >=95% single accuracy at fixed CAL/DEV); include its necessary TRAIN exposure consistently or limit a weaker check to measured common-prefix learning and enough actual source opportunity support. Failing this means the general capacity hypothesis was not adequately tested; even a valid negative is local to the chosen scale/training regime.

Measure end-to-end same-data warm latency as well as cold setup separately: actual tokenization, state reset, incremental/local processing, summary write/index/read, eligibility checking/scoring, routing, gather, fusion and output. Predeclare timed units and exclusions, warmup and interleaved order and enforce output parity on every timed repeat. Record wall p50/p95 with per-seed paired case contrasts, stored/transferred/working bytes and optional separately instrumented peak memory, actual CPU time and estimate touched operations, plus speed of fixed simple controls. Kernel latency is not complete cost. No claim of lower total cost from a reduction in selected packet count alone; no production serving implication. No auxiliary paid storage/compute commitments.

## Ecosystem stages and claim boundary

Native Forge → TrainLab → Veritas → Research Lab; standalone prep/inert tests are not executed evidence. Pin repository+branch+exact commit and parent, local content hashes when unpublished, dependency/runtime binaries/configuration and tokenizer hashes, exact split/projection and source data manifests, recipe commands/destination/CPU caps, observation producers, independent reviewer and author roles, native policy/evidence state, exact predecessor receipts, stdout/stderr/checkpoints/predictions and verification hashes. Emit separate immutable scopes for DATA-only, FIT-only, blind PREDICT-only and VERIFY-only (inputs/outputs explicit, unique attempt markers, unsigned claimed identity does not by itself establish independent review). Verify native output integrity and record failures and actual elapsed counters. Veritas independently recomputes score and decision from saved predictions and sealed truth; Research Lab retains links and study + per-arm statuses. Skill/runner green is not evidence of scientific success.

A valid positive supports only a causal communication diagnostic on those finite constructed panels with the declared controls. It does not establish language competitiveness, generalization beyond the held construction, persistent semantic memory, learned binding, performance against Transformers/SSMs as a class, equivalence to historical PULSE, general inference/production advantages, continental leadership, or cross-machine replication. D remains a distinct hypothesis.
