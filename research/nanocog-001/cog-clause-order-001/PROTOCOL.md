# COG-CLAUSE-ORDER-001: Clause-order symmetry

**Frozen before fitting.** An isolated CPU mechanistic study; no prior held data, MAIN, or protected TEST. Tests eight raw tokens: two three-token independent assertions and one two-token query. A distinct 24-entity, four-relation, 12-value lexicon and new two-key grammar are used. No claims on syntax transfer or long-context learning. This is not a continuation checkpoint and is not authentic-language transfer. Slot positions are an explicit fixed-grammar prior, never supplied gold record/answer identities. Reordering revisions to the same key is not a valid symmetry and is out of scope.

Primary comparison: same learned clause encoder, query encoder, soft gated messages and unrestricted vocabulary decoder. SYM presents both messages with an identical learned positional feature, ORDER with opposite learned positional features. All tensors, parameters, data, optimizer and step counts otherwise match. RAW is a competent two-block plain causal attention control over the same raw eight tokens, near parameter matched; no claim of matched FLOPs. Neither clause arm uses literal token lookup, direct copying of supplied gold IDs, a typed executor, or additional supervision. Clause scoring is bounded two-candidate retrieval and functionally similar to soft attention; this is not a demonstration of general attention replacement.

Derivation: if q is fixed, per-clause weights a(c,q) and values v(c) share parameters and identical positional features, then normalized sum Σ a(c,q)v(c)/Σ a(c,q) is unchanged by permuting the two clauses. Therefore SYM logits are unchanged in exact arithmetic; report float tolerance. It does not imply correctness or flip sensitivity. Structural tests include the order-sensitive control and future-token masking in RAW.

Families are assigned by unordered entity/relation key pair, held out as groups, with all individual tokens exposed in training. Fix 64 held groups per same-entity/different-relation, same-relation/different-entity, and different-both stratum, each with 4 base histories. All train and held base histories have 24 rows: both queries, both clause orders, base, each of two independent one-value edits, value swap, and the two single edits of that swapped assignment. Include all rows of a sampled bundle in training, and compare every arm under same single full-vocabulary CE. Gold labels appear only in training and offline scoring, not model forward. Of particular interest are the two strata that rule out entity-only and relation-only matching. Random labels and key overlap checks are data audits; scoring uses unique full-vocabulary argmax.

Seeds 3371,3471,3571. 1024 AdamW steps, batch 8 complete bundles, LR .002 with cosine floor .0002, weight decay .01, norm clip 1. No checkpoint selection. Before scoring held evaluate 64 distinct in-pool training-audit groups per stratum, each 2 fixed calibration histories (not a separate generalization claim). Adequacy: >=95% all individual rows and >=90% all-eight ordinary (base and swap across two queries and orders) in each train-audit stratum. Held absolute gate per stratum and seed: >=95% individual, >=90% ordinary families, >=90% target-following & distractor-preserving triplets independently for each physical query clause, >=90% both-order strict triplets, and >=90% complementary value-swap pairs. Report joint all-24, order agreement and max mirror logit difference separately; agreement is not accuracy. Compare exact seed-paired rates without claiming statistical superiority solely from thresholds or treating histories from the same key pair as independent. Always report failed gates and the adequacy failures before causal claims. No large fit, fixed-slot retention, production throughput or native qualification promotion.
