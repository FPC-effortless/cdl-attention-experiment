# COG-MATCHED-BOUNDARY-001

Question: does a learned additive compatibility function improve binding or revision under the same visible clause boundaries as dot-product attention? This is a matched selector comparison, not a claim to replace attention. Both are attention-style normalized weighted reads.

Both actors accept only visible strings. Split on standalone period tokens into 3 clause segments plus query. Order is visible and both arms receive the same normalized chronology coordinate for each clause. Same initialization of common parameters; identical clause tokens, learned phrase encoder, projections, clause values, query residual, full-vocabulary decoder and cross-entropy objective. Both use one parameter vector in the scorer: score = sum(g*k*q)/sqrt(d) vs sum(g*tanh(k+q))/sqrt(d). Same parameter count, not same FLOPs. No parsed keys, times, query type, target IDs, truth labels, masking except padding, or hard executor in forward.

Separate strict all-four outcomes for binding (opposite queries and evidence order), exact-date lookup (opposite queries and chronological evidence reordering), and untimestamped latest-mentioned revisions (reverse evidence order and swap payload; reversing mention order must change the answer). Each family includes a visible wrong-key distractor. Synthetic known and new syntax cannot establish transfer to authentic language. No previous sealed material.

Fixed three seeds 4371,4471,4571. 1,024 AdamW updates, batch 16 four-row families, CE over all vocabulary tokens other than padding, lr .002 cosine floor .0002, gradient clipping 1. Fixed endpoint; no retry or checkpoint selection after scoring. Train 512 families per mode, calibration 128 per mode, seen and unfamiliar eval 256 each per mode. Same calibration and held rows for each arm; fit receives only train/cal. In held prediction the predictor sees text only and records full-vocabulary logits and traces of all three weights. Offline scorer checks raw wire identity, unique maximizers, strict all-four rate and target selection (diagnostic, not necessarily causal). Qualification for each seed: >=95% individual and >=90% strict in all three calibration regimes and each held mode in both syntax cohorts. Aim to infer selector differences via count differences at matched quality, all seeds visible; no claim from pooled comparison if calibration inadequate. Report syntax drops, difference by mode, and applicability of strong equality/structural priors. No long-context, efficiency or learned-boundary claim. No paid compute or protected test data.

Novel held uses disjoint two-word keys and both familiar modifiers at once, which otherwise co-occur only across sentences in training, so plain seen-vs-novel differences mix key and wording changes. A non-gating paired rewrite panel keeps every seen family, fact, query, order and target fixed, adding familiar modifiers to each span only where needed to put both sides around each span. That measures the effect of this precise wording intervention; it is not an authentic paraphrase benchmark. Frozen result split: hashed after construction and before fit, filesystem-local actors are code-separated, not a claim of externally secret custody.
