# COG-LM-002 protocol

The 30M seed-17 continuation protocol from 001 closes the missing 524,288-target Mamba-2 comparison. Apply the original validation-selected scalar successor mixture. Use the frozen 001 WikiText-2 test and MultiWOZ transfer windows.

For the second stage, hold the 524,288-target sequence processors fixed and fit a residual language adapter, a learned successor mixture gate and (in the revision arm) eight content-addressed key/value records. This tests late acquisition of memory at fixed backbone scale. Use the same 1,572,864 additional natural-language targets in each arm. Sample 12,288 distinct, nonoverlapping 128-target windows from WikiText-2 training articles without replacement, preserving article boundaries. Earlier 001 targets may overlap these. Keep the same readout initialization and data order in the paired COG arms. Keep all gradient paths through the new memory. Use AdamW with cosine decay and no probe supervision. The Mamba-2 + lookup arm receives the identical adapter and objective. Intervene on the full trained COG by disabling only its learned bank. These fits test adaptation, not end-to-end pretraining on 2M tokens. No parameter scale-up.

Score per-article NLL on both natural-text panels. Score counterbalanced held-out wording and changed assignments against the complete vocabulary, stale-answer preference, and both directions of the counterfactual pair. Test 256, 1024, 4096, 16384 tokens of intervening natural text with unassisted model input. Cross entity identity with value assignment and include literal controls. Negative controls retain lookup capacity and use the same prompts. Freeze probe wording before scoring. Record budget mismatch where removing the bank saves compute. Benchmark at batch one, inclusive of state maintenance, with per-stage timing and retained storage. Run float32 parity and causality checks. Record trained checkpoints and dataset/offset digests.

Promote the revision bank only if it improves held-out natural-text prediction and reworded revision over both trained simpler alternatives, with convincing paired evidence. Conditional article intervals at one seed do not estimate variation across retrainings. Reused 001 test panels and constructed probes do not qualify a general language agent.

## Authentic dialogue extension

Before inspecting any new model's evaluation scores, add a separate real correction panel. Take changes in annotated slot values from MultiWOZ 2.2 test dialogues_002.json at the 001 source revision. Require a unique earlier and updated value, an explicit word-boundary match of the earlier value in preceding user speech and an explicit match of the updated value in the change turn. Feed the literal transcript and a fixed question about the requested attribute to the four jointly trained conditions. Keep annotations outside the model. Compare complete lexical answers ending in a period before and after the correction. Report how often preference actually switches from stale to updated, plus a two-candidate most-recent-mention heuristic. This panel measures explicit revisions. The forced-choice comparison supplies candidates to the scorer and can be solved by literal recency.
