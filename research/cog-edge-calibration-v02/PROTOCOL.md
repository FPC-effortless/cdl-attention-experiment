# COG-EDGE separate calibration and residual audit v0.2
Passive battery voltage telemetry only. Developmental, post-result analysis of the previously scored 215-flight cohort; no independent new vehicles or flight operation claim.

## Frozen design before running
Use the exact pinned source and original training/test partitions of expanded run 46052547333, original 1 Hz battery-only telemetry arrays and hash checks. Divide original model-selection pool by recorded battery label into a model-selection subset and a separate calibration subset. Choose a balanced partition by flight counts only, with both donor aircraft represented in both subsets and four calibration pack labels in each fold. Frozen list in splits.json. No model uses calibration/test for gradients or checkpoint choice. Fresh fits from initialization: all original five architecture arms, three original seeds, all three folds, 600 updates, same training windows and optimizer, same training arrays. Calibration and test panels not constructed until all fits in a fold are saved. Test cohort and masks unchanged for comparison; it has already been scored, so this is not a blind qualification cohort.

## Calibration and diagnosis
Four predetermined empirical scale-factor policies, per forecast horizon: pooled 90th residual/scale quantile, stratified by current voltage-observation age (0–3, 4–15, 16+ seconds; pooled fallback if <100 targets or <3 calibration pack labels), conservative age (max of pooled and stratified), and maximum per-calibration-pack 90th quantile (at least pooled). Report all variants, all arms and seeds, all horizons and regimes, coverage and width jointly; point forecasts identical across policies. No use of nominal simulated dropout rate as model feature; no test-driven policy selection. Only 4 independent recorded calibration labels per fold, overlapping time series and held-out-aircraft shift, so no formal conformal or population coverage guarantee. For original COG weights, compare recorded metrics to independently recalculated intervals, then stratify errors by current observation age and last-observed voltage/current bins (training-only terciles; stale estimates, not contemporaneous true load). Publish grouped count, RMSE, MAE, bias, coverage and interval width; no raw point-level telemetry. Do not interpret missingness fixtures as actual faults.

All 135 checkpoints including initial/selected/final weights and optimizer/RNG states, flight-level and stratified metrics, partition receipt, acquisition logs, environment and hashes must be committed to run-specific Git refs. No raw third-party data publication: no explicit redistribution license located in upstream pinned repository. Reconstruct training data by source revision and exact hashes; request written permission separately. Do not merge, promote, or relax scientific hold. Replay #104 remains an independent gate. Hardware testing and new airframes remain outstanding.
