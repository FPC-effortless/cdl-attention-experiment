# ASSOC-005 — Noisy recall into typed state and acquired procedures

Prospective integration engineering diagnostic. Construct fresh stores at seeds 101, 211, 307, each containing 256 unit 64-dimensional random keys. Token IDs encode four operations, sixteen registers, 235 literals and one padding symbol. Balance 256 four-token packets per store across SET, COPY, SWAP and ROTATE3. Independently reset a sixteen-register state and empty scratch per packet. Distinct operands prevent degenerate operations. Decode four noisy cues using full exact nearest-neighbor search or global 32-bit signatures on dimensions 12:44 followed by at most 32 exact comparisons per cue.

At noise standard deviations 0, 0.09 and 0.18 per component before normalization, validate all decoded roles and padding before executing. Reject invalid packets atomically. Reuse the prior COPY executor and infer SWAP and ROTATE3 from state traces. The correct final state is independently calculated from the original command. Measure exact packet recall, correct final states, rejected packets and committed incorrect final states by operation. These semantic types and grammar are supplied.

Replay the same query packets for both arms. Timings include query signature creation, candidate sorting, four retrievals, type validation, macro binding and state execution in a common per-packet loop. Exclude key-store construction, stored-signature precomputation and program acquisition. Warm both arms once; alternate order over twelve measured blocks. Record batch times and report median per packet on the same workload. This measures one local NumPy implementation and a bounded integration surface. Fresh stores extend development diagnostics without scientific qualification or integration into the original neural CSM controller.

## Internal design review

The scientific-review subagent approved this integration diagnostic conditional on atomic guards, nondegenerate gold effects, exact grammar and independent oracle effects. IDs 0:4 identify SET/COPY/SWAP/ROTATE3, 4:20 identify registers, 20:255 are literals mapped to values 1000:1235, and 255 is padding. SET requires operation/register/literal/padding. COPY and SWAP require operation/register/register/padding. ROTATE3 requires operation/register/register/register. All referenced registers are distinct. Keys, packets and Gaussian innovations are shared across noise scales. Initial state is registers 0 through 15 containing their indices, with empty scratch; each evaluation starts from this immutable state. Per-packet records include gold and decoded IDs to preserve confusion and equivalent-effect analysis. Exhaust every single-symbol substitution for one example of each operation to check guard and oracle consistency before scoring.
