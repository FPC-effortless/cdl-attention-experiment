# CSM-BDH-002 governing-clause experiment

Three paired fits per arm on 240 reversal pairs per seed. Both members contain identical word multisets and require opposite expressions. Local lexical features are inherited from the prior span reader. Wide features also encode six signed offsets on each side of every candidate. Training uses exact span supervision. Test phrase vocabulary is disjoint. Demonstration outputs are supplied record names. Both readers search all one-to-three-word spans and use learned episode bindings with a frozen record encoder and conditional executor. The control supplies correct spans throughout.

Each layout contains the same 96 fresh episode rosters crossed with six assignments of familiar demonstration frames to expressions. Queries and demonstrations have a common supplied record prefix. Each query triggers four execution checks, crossing which guard record exists with COPY or LINK, followed by a source edit. A wrong commit counts one unauthorized conditional operation; abstention counts one query. These denominators differ. Repetitions across seeds, permutations and layouts share episodes. A passing pair requires both correct spans, slots and executed outcomes. The threshold is 92/96 per cell. The three learned layouts beyond the familiar verb frame all yielded zero jointly correct pairs, across seeds and assignments. Local familiar range 41–78/96, wide 96/96. The oracle passed throughout. Neither candidate qualified. See scores.csv for counts per cell.

For the post-hoc query-only boundary intervention, both correct candidate locations are supplied and neither meaning nor winner is supplied. Each selector ranks those two spans using its saved coefficients. Both readers still scored zero correct pairs on every transfer layout. This localizes a failure in ranking even with exact boundaries. It does not distinguish lexical unfamiliarity, attachment or position bias. One external grammar example was adapted into the preference frame; it exchanges the expressions, while the other three layouts exchange the authority words. This is an investigator-assembled diagnostic, with no blinded human-authored evaluation or efficiency claim.

Replay in Python with numpy, pandas and scikit-learn. Run study.py, then audit.py and boundaries.py from this folder. design.json contains the frozen settings and source. The inherited run.py is provided for its span helpers. study.py is the experimental entry point.

The complete handoff package contains the archived raw outputs and weights described above. The GitHub checkout includes the inputs needed to regenerate these outputs.
