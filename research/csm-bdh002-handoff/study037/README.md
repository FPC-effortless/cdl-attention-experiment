# CSM-BDH-002 expression-to-approval attachment

Run experiment.py then audit.py and collision.py with Python, NumPy, SciPy, pandas and scikit-learn. The three seeds use different paired training examples and the same 96 fresh evaluation rosters. Each evaluation pair keeps expression positions and words fixed, reversing authority. Supplied candidate spans and supplied episodic phrase-to-mention directions isolate query attachment. All readers use the archived frozen record encoder, gate and typed COPY/LINK executor. This removes demonstration binding as a source of errors. Each query tests both operations and both states of the guard. An unauthorized operation is counted separately for each operation. Repeated tests reuse rosters. This diagnostic has no natural-language holdout or throughput comparison.

The wide comparator is refit using candidate-pair supervision. The pair model scores both one-to-one assignments between supplied expressions and detected cue positions, using a learned bias, log gap length, and intervening conjunction counts. A second learned score assigns polarity to the cue identities. Their marginal determines the selected expression. The four-word cue vocabulary and conjunction vocabulary are engineered. The pair model receives the same candidate labels and examples as the wide model and receives a lexical cue inventory as an additional inductive bias. Heuristic order control uses supplied lexical polarity.

The gate failed. The pair reader passed five of six layouts at 96/96 each per seed. Its answers matched the order heuristic throughout. The wide model passed three layouts. Its 32/96 on the reversed list consisted of correct or abstaining decisions. Check scores.csv for exact counts per seed and arm. The oracle passed all six. As a post-hoc diagnostic collision.py swaps only former and latter at fixed positions. This leaves every feature entering the pair decision identical while the required expression changes. No adjustment to the learned weights can resolve both members given these features. Future work should model the link from a referring word to its antecedent, with both ordinary and inverted order during training and new templates reserved for evaluation.

The complete handoff package contains the archived raw outputs and weights described above. The GitHub checkout includes the inputs needed to regenerate these outputs.
