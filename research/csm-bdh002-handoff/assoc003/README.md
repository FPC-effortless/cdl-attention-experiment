# ASSOC-003 — Candidate ranking within two noisy sign banks

Engineering diagnostic on the same nine development panels as ASSOC-002. Keep the original bank order, two probes, queries, and 32-candidate budget. On overflow, rank candidates by Hamming distance on coordinates 3 through 18, disjoint from bank addressing. Preserve the original candidate order for ties and perform the original full-dimensional nearest-neighbor comparison on survivors. Compare to insertion order. Count true-key survival, exact cue and packet recovery, the observed four-cue routing ceiling, signature bytes, Hamming comparisons and full dot products. Use packed uint16 signatures. This fixed-cap implementation uses stable sorting, so comparison counts exclude sorting and do not establish latency. No new random seeds or neural models enter this test.
