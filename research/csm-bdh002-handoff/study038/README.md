# CSM-BDH-002 reference binding

Train a four-weight logistic model on 240 synthetic quartets per seed. Each quartet crosses the order of two references with the placement of accepted and discarded. The winner label teaches how each reference word maps to expression position, using a supplied inventory to detect reference words. The same minimum-distance cue-to-reference matcher runs before both the learned mapping and the fixed dictionaries. The ordinary dictionary covers the four training words. The expanded dictionary also contains earlier and later. The order control ignores reference words.

Each layout and seed has 96 evaluation quartets. All four queries in a quartet must select the correct expression, route to the correct record, and reproduce the expected effects of conditional COPY and LINK under both guard states. The gate is 92/96 in every cell. Wrong authorizations count once per COPY or LINK operation. An abstention counts once per query. The three seeds share evaluation rosters. Candidate expression spans, phrase-to-record directions, and the inventory for reference detection are supplied. The frozen encoder and transaction executor come from the preceding study.

The learned and ordinary dictionary arms made identical predictions across all 6,912 matched queries. Both scored 96/96 per seed on familiar wording, held-out approval-first syntax, long gaps, and grouped references. They failed the prior threshold on the other two layouts. In the repeated-reference layout, an introductory comparison competes with the governing references. The minimum-distance matcher uses the wrong reference on every query, leading to 768 unauthorized operations per seed. The expanded dictionary fails the same layout. On unseen aliases, the learned and ordinary dictionary arms abstain on all 384 queries per seed. The expanded dictionary passes the alias layout. The order control fails every quartet, and the oracle passes all quartets.

The prespecified experiment used one reference-pair inventory and investigator-authored synthetic frames. Two post-hoc interventions isolate the failures. Removing the introductory comparison from the repeated-reference cases restores the expression decisions on all 384 affected queries per seed. Supplying the two alias associations restores the alias decisions on all 384 queries per seed. Those checks score expression selection against archived oracle predictions. They reuse the original fixtures and evaluate neither learned clause segmentation nor automatic alias learning. Natural-language generalization and inference cost were outside this diagnostic.

Run experiment.py, audit.py, and interventions.py using Python with NumPy, pandas and scikit-learn. The protocol, trained weights, raw predictions, derived scores and supplied controls are bundled.

The complete handoff package contains the archived raw outputs and weights described above. The GitHub checkout includes the inputs needed to regenerate these outputs.
