# COG-065-E1: is there room to learn a communicator?
Frozen deterministic eligibility, **no learner**. Separate from COG-066, whose primitive execution witnesses inform the local completion semantics; no macro/acquired options. Constructed only, no protected TEST, spending, external transactions, communications or writes. Exact independent preflight before any held comparison. The 16-word channel counts EOS and allows ordinary controlled sentences only.

## One comparison and decision
Same full bounded receipt snapshot, role and public prior for every sender. The recipient gets only the emitted message and its own private context, never hidden receipts, condition name, alternate branch, sender cache index or gold action. Prespecified four equally likely receiver contexts per role, complementing different combinations of sender facts. Conditions:
1. no message (EOS only);
2. 16-word exact same-information optimum (all legal clause subsets enumerated, expected correct recipient action under the known public four-context distribution);
3. full-budget exact same-information optimum (same objective and prior, all legal subsets up to 64 words, not a hidden-truth oracle); report forced all-fields separately only as a diagnostic.
Checks: neither unknown facts nor an action verb appear as proof. Missing required facts give a safe request-for-evidence/referral rather than assuming a completed action. Receivers independently decode message tokens; exact sender uses only virtual public states, not a runtime recipient context. Evaluate the same four contexts for each paired constructed group. This design deliberately enumerates the exact true prior, so a learned ranker cannot beat condition 2 in expected decision quality. A real cost advantage is the only possible future reason to continue with learned approximate selection.

Freeze useful-medium conditions: paired 95% bootstrap interval lower bound > 10 pp for exact16 vs no-message, and > 5 pp for full vs exact16 (whole source group resampling, 5,000 fixed draws); report by role and paired variants, no extrapolation outside synthetic rules. The full/no-message anchor is feasibility, not a production claim. Danger guard zero false completion or simulated resume when reference is not that action; no massaging gold labels. Preregister deployment-oriented cost hurdle for this small local finite CPU setting: if exact cached selection is <=0.25 ms p95 warm per request and complete exact acquisition+message+verification is <=1 ms p95, **STOP learning**, even with a material budget gap. If cache is cheap but absolute gap exists, increase the channel or redesign vocabulary when authorized; do not call it model deficit. Also stop if cache exactly matches the reference and independent timing finds no realistic room against the same-input codec. Timing records one-time full table compilation, bytes, complete warm/cold uncached costs, p50/p95 and all repetitions; no invented 12:1 scalar. A cost miss is not a learning win and requires separately reviewed proposal.

## Receipt schedule, occupancy, availability and boundary isolation
Every raw record consists of a trusted envelope {slot, tick, sequence, payload}. The queue captures availability and signed order independently of the payload. Point-in-time cutoff is a trusted integer tick with closed same-tick boundary: all available records at the tick are eligible before semantic parsing. Within each slot the maximum (tick, sequence) occupies the slot; a conflicting position at an eligible equal (slot,tick,sequence) rejects the snapshot before parsing; a repeated delivery of the same admitted immutable envelope is idempotent; distinct envelopes at the same position reject. Records outside cutoff are neither semantically parsed nor allowed to supersede earlier slots. A malformed or future payload cannot change an earlier snapshot. Superseded occupants are never parsed. Do not retrospectively rewrite snapshots with future fields or use list iteration order to resolve same-tick ties. Strict known schema versions 1/2 normalize losslessly on occupied records; unknown occupied payload fails closed. Per-field slot models stand for derived receipt atoms, not general cryptographic trust.

## Admission and audit limits
Preregister 72 independently generated source groups (24 per role). Each includes a reference and one paired authority/provenance perturbation sharing random seed, schedule layout and listener roster; grouped bootstrap rather than pseudoreplication. Known version renderings alternate by group independently of outcomes. No sender or receiver model fit. Provider identity is a named schema field; current primitive completion proof and authorization remain distinct. Ground truth from complete authorized local prefix and independently interpreted rules; keep one observable cohort and separate private contexts/expected outputs, with rule equivalence verified on hand-authored fixtures. No receiver real actions: report local transition symbols after applying the rule. Structured provider messages are not natural language generalization. Exact prior does not transport to arbitrary outsiders or unseen roles.

Use pinned Forge→TrainLab→Veritas→Research Lab. Freeze held views as bounded diagnostic input; preset evaluator only declares base group and private contexts. Exact TrainLab execution uses engineering_diagnostic because there is no fit or scientific qualification; no bypass for future training. Independent review exact source/data/rules before declared held run. Native Veritas-style adapter recomputes transitions from retained strings and checks legal encoding, chronology, expected scope and output hashes. Research Lab registers immutable one-stage evidence and replay only by scoped authorization. Mechanical fixture checks may execute before review, no held outcome, time/feasibility conclusion or published result before launch admission.

Three roles each have four equally weighted known field-patterns. The patterns are published; the realized context is held only by evaluator. The source is deliberately small: one primitive parcel requiring two picks separated by bay travel, executed via the unchanged exact primitive step and completion definitions. Paired perturbations independently change authority, source verification, scope or freshness, and declared progress/status depend only on the recorded primitive prefix. Any simulated 'resume' is checked for a locally legal useful primitive against the frozen reference, not treated as safe because it is a label match. This is not an actor system or physical action; raw semantic atoms in the proposal do not represent reviewed signatures from natural providers. Timing includes identical arrival/occupancy/parse and receiver proof check even when no-message, where appropriate; publication and real external actions excluded.
