# Reproduction scope

This is an acquisition and implementation handoff, not authorization to execute. Reproduce with a local owner and independent reviewer, operator-private storage, no original publisher DEV/TEST, and native TrainLab review. The public bundle cannot substitute for genuine local admission. Do not select a new policy using E now that its outcome is known.

1. Rebuild a local CPython 3.12 Linux x86_64 environment against the exact public Veritas ecosystem revision in runtime/BASE_VERSIONS.json. See runtime/README.md. Set OpenBLAS, OMP and MKL threads to one and independently bind actual runtime.
2. In a private study root, copy the files in source/prepare/ into `source/`. The acquisition script expects to run from study root. `bash source/acquire.sh` requests only 17 immutable publisher TRAIN shards and metadata. With exact Forge on PYTHONPATH, execute `python source/prepare.py`, `python source/split_eval.py`, `python source/overlap.py` for local A/B/E, isolated role files, and Forge diagnostics. Generated input, labels, predictions and models remain private. This source bundle does not redistribute transcript rights or personal data.
3. Use the selected original or binary code as frozen scientific inputs. Supply independently vetted native TrainLab recipes with one-stage-only custody. The A/B fit receives only A/B rows, code and pinned scalar preflight/support receipts. The native research-adequacy contract must reconcile observations.json with the pinned recipe and inputs. The original three-class and binary fit contracts have different support and model-size requirements; follow each protocol, never override retroactively. One 240 s primary and one same-budget 240 s replay, one CPU thread; preserve any failed attempt. A match on the original host does not guarantee checkpoint bytes across machines.
4. A separate review must bind the exact fit receipts/checkpoint, and approve one no-fit E-input-only stage (predict.py, model.py, verified heads.joblib and E-input.json). A different review must bind the successful prediction receipt/output before staging E gold. Binary scorer invocation inside its TrainLab stage: `python score.py predictions.json data/E-gold.json data/E-overlap.json`. Each stage has a 60 s child deadline; TrainLab sets TRAINLAB_OUTPUT_DIR. Native Veritas evidence and Research Lab linkage are private. This package intentionally omits private orchestration/tokens; construct and independently review local stage configuration. Do not recreate prior tokens or combine score and prediction admission.
5. Compare retained aggregates without claiming exact runtime or source equivalence from version strings, external transfer, modern model ranking, production write cost, or scientific qualification.
